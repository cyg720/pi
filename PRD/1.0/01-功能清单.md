## 1 版本边界

固定使用 pi-durable。单用户、本地部署、云端模型 API、Web 优先。内置 `lg-codeing-agent` 和 `lg-examine`：前者完成编码任务，后者独立做验收、对抗审查和整改复核。两者各有包、指令、工具和会话，共用平台服务与模型配置。新增单用户工具审批：手动、自动、完全访问；这是本轮已确认的范围变更。

1.0 不做平台账号、角色权限、多用户、桌面端、手机专版、插件市场、通用多智能体协作和旧会话迁移。模型厂商授权属于连接配置，纳入本版。不改原 coding-agent，不通过旧 SDK 或 PI CLI RPC 运行。

用户手动选择智能体和发起审查、复核；不自动派单、自动整改或循环互审。编码智能体纳入 Durable Code Mode；审查智能体不装配 Code Mode。

项目与智能体是独立对象、多对多使用：项目保存名称、目标、资料和成果；平台统一登记智能体定义。新建项目不绑定某个智能体；在项目内选智能体创建会话/任务，同一项目可同时运行多个，同一智能体也可用于多个项目。参与关系从会话和任务汇总，首版不另做成员权限或自动编排。

冲突按资源处理：同一可写工作目录只允许一个写任务；源目录取材需短时读取占用，不能与该目录写任务并行。快照发布后立即释放源目录占用，后续审查仅占自己的执行名额/检查副本。路径别名、父子目录跨项目也检查冲突；首版不对任意 Shell 做细粒度文件锁或自动合并。服务设置有限的并发上限，默认至少允许两个会话；满额或资源冲突明确提示重试，不自动排跨会话任务。

资源冲突显示持有项目/会话；尚未准入的请求可重试。取材、模型调用及收尾共用一次准入标识，停止按钮绑定该标识，不会误停后来任务。后台压缩、进程和必要归档未结束时仍占名额；编码差异归档后才释放写目录。取材失败或停止收尾后释放，不长期占住名额等待用户。

检查副本、执行环境、进程和临时目录按执行分开。已知依赖共享可写目录、固定端口等而无法独立准备的审查检查标无法验证；1.0 不提供这些外部资源的并发调度，不承诺任意命令已被系统沙箱隔离。

首版本地服务只监听本机回环地址，Web 与接口同源。服务进程活着才能持续运行；进程退出期间不执行，重启后恢复。不承诺断电前最后一次写入必定保留。

### 直接发送、同会话复核与快速定位

- 编码、审查均直接发送；运行中默认排队，支持编辑、撤回、立即插入和清空，详见“输入和停止”。没有“开始新任务”或发送方式下拉。
- 审查就是普通对话：没有准备表单、审查轮次、固定步骤条、确认标准按钮或专门复核入口。缺要求和材料在聊天中补充；整改后继续发送，页面会话和 Durable 会话均不变。
- 切智能体或右键分支才建立同项目独立会话，不自动执行。来源背景只是参考，不继承队列、批准决定、工具执行或已通过结论。
- 两类会话都按已保存用户消息建立刻度，悬停/聚焦看摘要，点击或 Enter 定位；按稳定 entryId 分页，压缩后仍能读取旧历史。定位不调用模型。
- 浏览器保存实例/项目/会话和主动定位消息，刷新先校验再恢复；网络失败保留待重试，确认失效后回退并提示。队列、执行状态及统计重读服务端，不重发消息。
- 审查正文和输入区最大 1100px 居中，窄处缩放；右下智能体/模型/思考档，左下材料/审批，材料标签在输入框外上方。回复中的证据可打开固定版本文件。

同会话保留正常历史与压缩上下文；证据仍按实际请求/执行固定来源。新消息改变要求或材料须留下关联，不能改写旧结论或恢复时偷换源文件。

### 统计底栏的统一口径

统计只读，不影响任务预算和调度。编码、审查均汇总当前页面绑定的 Durable 会话；浏览旧消息不截断累计量或切换上下文范围，分支不重复计入来源背景。悬停或聚焦可查看以下说明。

| 显示 | 口径 |
| --- | --- |
| N 轮 | 两类会话均为已进入历史的 UserEntry 条数，不计草稿、未消费队列、系统摘要、控制消息和分支背景；这是消息计数，不是审查轮次 |
| N 步 | 每条已落盘业务 AssistantEntry 算一步，含错误/中断响应；工具结果不再计一步，审批/压缩不计业务步。重试只有实际落盘的响应才计，重放不重复 |
| N tok/s | 最近一条已完成且 output 有效、durationMs > 0 的业务响应，output ÷ 耗时秒数，含模型报告的推理 token；悬停标“最近完成响应，含请求等待”。没有有效数据为“—” |
| N tok | 范围内 UsageDoc.models/tools 的 totalTokens，加独立审批账；审批不得再写入 UsageDoc，工具只报自身用量，不包含已单独记账的子工具消耗，包含压缩，推理已含在 output 不再加。不是厂商账单 |
| 缓存命中 N% | UsageDoc.models（含压缩）合计 cacheRead ÷ 合计(input + cacheRead + cacheWrite)，不计审批/工具桶。分母无效或缓存读写全零显示“—”；有缓存值时显示回执比例并标“部分统计：字段可能缺报”，不宣称真实命中率 |
| 圆环 N% | 当前会话有效上下文估算 token ÷ 会话保存的当前模型有效上下文上限；标“估算”。无上下文/窗口为“—”；超过 100% 显示真实数值，圆环最多满圈 |
| 状态 | 右侧显示当前会话真实执行状态；查看旧消息不改成历史任务状态 |

业务用量和审批用量详情分开，费用缺价显示未知。新会话未发送、总览、目录和设置不显示旧统计。刷新/断线重连以服务端版本快照替换，不能重复相加；缺数据不编造 0 或原型样例值，断线保留最近值并标未更新。原型的 44 步、233 tok/s、4M、94%、13% 仅是视觉样例。

源码用量只有模型/工具汇总桶，没有调用编号和“缓存字段是否上报”标记。不能承诺从桶里事后去重，也不能从模型名称猜缓存能力。缓存缺失可能已经被适配器补零，1.0 采用上述保守显示；不区分得出的零值不能写成 0% 未命中。

业务总量以 UsageDoc 为准，审批账按稳定审批请求去重；父工具不再上报子工具已计用量。历史原文不是完整费用账：压缩消耗可能没有 AssistantEntry，不能只加消息 usage 替代 UsageDoc。轮步数是产品计数，不等于 run 数；平台真实用户输入使用 UserEntry，分支背景及继续队列控制记录使用独立来源标识，不计入用户消息。

上下文取当前会话及保存的模型窗口，缺记录显示未知，不用最新目录补旧绑定。显式切模型后重算；初次请求前没有有效上下文则未知。公共 context() 不包含全部最终请求加工，圆环始终是估算。“完整”只指已保存来源读全，不保证厂商实际消耗没有漏记。

### 页面布局与状态保留

- 左侧从上到下为新建项目、项目/会话列表、智能体区、连接状态和设置。项目下会话按项目平铺，分支标明来源，不做完整分支树；项目列表独立滚动。
- 智能体区默认列表最多四行；方块为两列、最多两行，超出内部滚动。短窗口可减少可见项，不能挤掉设置。当前仅两个内置智能体，不为填满区域新增能力，也不在顶部重复放目录入口。点击智能体预选当前项目，仍可更换项目。
- 顶部导航显示项目/会话名称，下方展示项目路径，长路径省略且悬停可读全；正文不重复标题/状态栏。右栏不放“项目资源”标题、底部项目名/路径/样例说明，也不放文件树上方分支行。目录内文件逐级缩进，根文件与根目录同级。底栏固定显示统计及文字状态；模型切换放输入区，仍遵守忙时限制。
- 右栏按“文件、搜索、变更”排列；审查增加“已选材料”。右上角控制整个右栏收起/展开；结论从原消息打开，不提供成果页签。
- 左下设置打开完整页面，保留左侧导航，替换中间与右栏。集中配置模型连接、常用与默认模型、基础配置，全部项目共用；返回恢复原项目、会话、草稿及文件查看状态。
- 没打开文件时，会话占满中间。打开后窄会话在左、宽查看区在右，最右资源列表仍可操作；没有会话则左边保留项目总览。两区分别滚动，输入框和停止按钮可用。窄桌面可先收起资源栏，不能遮住会话操作或文件关闭按钮；不增加手机专版。
- 查看区顶部为横向文件标签，长列表横向滚动，每项可关闭。重复打开同来源同文件只激活原标签；搜索命中可更新定位。右上“隐藏查看区”保留标签，会话恢复全宽；顶部“查看文件 · 数量”恢复。关闭最后一项也恢复全宽。
- 标签以项目、相对路径、来源类型及具体执行/快照标识区分。当前文件、指定执行差异、工作区差异、各次材料快照不能相互覆盖；打开时固定的来源不随会话或消息切换。删除/缺失显示原因，快照损坏不能改读当前文件。
- 切项目、切标签、进设置及刷新均保留工作位置。浏览器按服务数据实例区分：当前页面和返回位置全局保存；搜索条件、资源标签、文件标签按项目保存；草稿与执行筛选按项目+会话保存。项目展开状态和列表/方块模式也保留。

### 新会话直接在页面里填写

- 项目行加号、项目总览“新建会话”、智能体入口都进同一个新会话页，不弹创建窗口。预选对应项目/智能体，任务框居中；暂时隐藏文件查看区但保留标签，仍能从顶部恢复。
- 输入框上方选项目；智能体、模型、思考档靠右，放发送按钮左侧，只显示文字与箭头，去掉按钮背景和边框，键盘焦点仍清楚。
- 不填会话名称。首次非空任务发送时创建记录，标题由服务端取首条任务去首尾空白、连续空白合成一格后的前 28 个 Unicode 字符；不截断 emoji 代理对，不额外调用模型起名。之后可右键改名，后续回复不覆盖手工名称。
- 编码和审查首次发送后都进入对话，输入框回到底部；审查先固定需要的材料再交模型，无额外准备/确认页。创建后资源受阻时保留同一会话和请求，用户重试不重新建记录。
- 未发送草稿按项目保存任务、智能体、完整模型引用和思考档，切项目不串；刷新或从设置返回恢复新会话页。空输入、无有效模型、离线时不创建；无模型可去设置再返回。无项目先引导新建项目。
- 连点和网络重试只创建一次；创建与首次提交分步记录，结果不明先查原请求。创建成功而首次提交失败时留在该会话重试原任务，不重建；刷新不自动发送。

### 右键重命名和删除

- 左侧项目、会话右键或 Shift+F10 打开菜单；重命名只改显示名，不改 ID、目录、智能体或历史报告。名称去首尾空白后须为 1—80 个 Unicode 字符，拒绝控制字符；重复名称允许，操作始终按 ID。保存后列表、导航与总览同步，刷新和重启保留。
- 删除前确认名称和范围；项目删除包含其下会话。产品使用持久删除标记：从日常列表移除并禁止新执行，不删除项目工作目录、数据库或历史证据；本版不做回收站、恢复入口和物理清库。审查仍可只读追溯引用的旧报告/材料，标记来源已删除，不能再启动该会话。
- 取材、已准入待提交、执行、停止/收尾、后台压缩、活动进程、待核对、保留队列任一存在则不能删除。项目检查全部会话；服务恢复未完成或状态读不全也不能放行。删除不是停止，不能顺便取消其他任务。
- 删除与新建会话/提交/继续队列串行检查；操作开始时空闲不代表确认时仍可删。重复删除返回原结果，旧页面和迟到响应不能复活记录；失败保留原列表并给原因。
- 删除当前会话回所属项目总览；删除当前项目转到其他有效项目，无项目显示新建入口。清理对应草稿、搜索、文件标签和设置返回引用；同项目当前文件仍可保留，已删除会话的执行/快照标签关闭，其他会话的证据链不删。

### 明暗主题与模型名称

输入框、文本域和有边框下拉聚焦或展开时，只把原有 1px 边框改为淡蓝色，不叠加 outline 或外圈阴影，不改变尺寸。搜索框和任务输入框改容器原边框。发送旁的纯文字下拉继续无背景、无边框，用淡蓝文字/箭头和下划线提示焦点；普通按钮保留键盘焦点。明暗主题都要检查。

- 默认暗色；左下设置旁用一个太阳/月亮图标切换，提示当前操作并可键盘触发。暗色使用深蓝底 `#0f1922`、蓝灰面板 `#1a2733`、浅色文字 `#d6e2ed`、青绿强调 `#55c5c0`；亮色沿用当前白底绿强调。
- 主题作为同源浏览器外观偏好单独保存，不依赖服务数据实例；首屏先恢复，避免先亮后暗。刷新、重新打开、清工作位置后保留选择；非法值回暗色，存储不可用仍可本页切换并提示保存失败。
- 设置、下拉、右键菜单、弹窗、代码/差异、提示和滚动条随主题切换；文字、选中、焦点、禁用及错误可辨。切换不重建会话、丢草稿/文件标签、改五处尺寸或中断订阅。
- 新会话、会话模型切换、默认模型选择只显示模型名称，不拼厂商前缀。优先目录名称，缺名称用完整 model ID；模型自身带 `/` 的名称或 ID 不随意截断。厂商连接设置仍显示厂商。
- 选项键、提交值、持久记录和路由仍是 provider ID + model ID；同名不合并、不按名称找第一项，选中勾按完整引用判断。目录重排/刷新、默认恢复都不能换连接；不可用则提示，不自动换同名模型。

### 刷新和重新打开

补充：新会话草稿按项目保存文字、智能体、完整模型引用、思考档、审批偏好及材料引用；切项目不串。已有会话草稿按项目+会话保存，可选检查参数随草稿保存，失效来源提示重新选择。历史回复和证据始终可追溯，有效来源标签失效时原位提示，不能用当前文件顶替。

原型只验证页面交互。三种真实审批、真实统计回执、服务端恢复及分页等仍须完成产品任务，差距见 [原型对照表](../../prototype/02-原型设计规划.md)。

| 保存什么 | 恢复规则 |
| --- | --- |
| 五处分界线尺寸 | 恢复上次已完成调整的值；窗口不足临时限制，不覆盖原偏好 |
| 当前页面、项目、会话 | 原来是总览/新会话/会话/目录/设置，就回该页；设置分类、所选厂商和返回位置也保留 |
| 新会话草稿、主题 | 草稿按项目恢复，发送前没有会话 ID；主题单独按同源外观偏好恢复，不等服务返回 |
| 文件查看状态 | 各项目标签顺序、选中项、固定执行/快照来源、显隐保留；恢复后从原来源重新读取 |
| 右栏与导航 | 右栏显隐、资源标签、项目展开状态、智能体显示模式保留；执行筛选按会话隔离 |
| 搜索条件 | 关键词、大小写、路径条件保留；结果和计数不缓存，可见搜索页签在服务可用且条件非空时重新查一次 |
| 主动消息定位目标 | 保存 entryId，先校验归属再定位；浏览旧回复不修改运行状态，不保存像素滚动值 |
| 未发送草稿 | 按项目+会话保存文字与材料引用；恢复不发送、不确认动作、不启动检查 |

- 新建项目、会话和已提交消息由服务端保存；浏览器收到创建成功后记住选中引用，刷新只读取，不重复创建。旧会话不在当前列表第一页时仍按 ID 查找，不能误判不存在。
- 页面偏好与布局分开保存，带格式版本和服务数据实例标识；刷新/关闭后重开同一地址可恢复。换浏览器、端口或设备不保证同步；同地址改用另一数据实例不串记录。初次使用没有偏好时采用默认布局和列表模式。
- 操作完成就保存，输入短暂防抖并在离页补存；恢复完成前不把默认状态写回。旧后台页面关闭不能覆盖另一页面较新的工作位置，其他页面保存也不能强制跳转当前页面。
- 先校验引用，再取服务端当前快照。确认会话失效或跨项目时回项目总览，确认项目失效时回项目列表；断网、服务恢复中或查询失败只显示重连/错误并保留原引用，不当作删除。
- 文件缺失或归档损坏保留可关闭的错误标签；不能用同名文件、当前文件冒充原快照。格式非法的缓存项跳过。当前文件内容变化后取消旧定位高亮并提示重新搜索，不沿用旧行号。
- 不持久保存文件全文、搜索结果、执行状态、队列、报告结论或连接/授权表单。模型连接从服务端读取，Key、OAuth 令牌和回答不进浏览器存储；有效授权流程仍按模型设置规则向服务端接回。
- 刷新不会提交任务、继续队列、停止任务、运行检查或自动生成审查回复。发送响应丢失时保留原 requestId 并查询结果，不自动重发；后台状态以服务端快照为准，不套用原型模拟计时器的恢复方式。
- 损坏缓存按项回退；不兼容版本有提示。存储禁用或满额时本页仍可用，提示下次可能无法恢复，不覆盖服务端记录。弹窗、下拉展开状态及像素滚动位置暂不恢复；主动消息定位引用按 U30 恢复；页面内设置返回仍保留阅读位置。

刷新还要保留分支/建轮操作的原 requestId、操作类型、来源、预期版本和草稿版本。操作中冻结的待确认输入与后来编辑的草稿分开；恢复只查结果，查不到也不自动创建。成功回执只更新所属记录，不清新草稿、不把已经切到别处的页面拉回。

消息定位、材料页签与统计响应均校验实例/项目/会话及本次页面请求代次。另一页面追加消息时，当前阅读位置保持不跳动；晚到的恢复或读取不覆盖新导航。统计仍属于当前会话，读取范围与完整性明确。

### 可拖拽分界线（U20、U23）

项目栏右边、会话/文件之间、资源栏左边可调宽；顶部栏下边、智能体区上边可调高。初始下限：项目栏 220px、会话区 280px、文件区 320px、资源栏 240px、顶部栏 44px、智能体区 100px；项目列表至少留 120px 高。上限同时受相邻区最小尺寸与窗口空间约束，到限停止。窄窗口资源栏可浮层显示，不能通过拖拽挤没输入和关闭按钮。

悬停高亮分界线，拖动中不重建会话；双击恢复该处默认，方向键微调、Home/End 到限、Enter 复位、Esc 撤销当前拖动。释放保存；取消、失焦或切页结束未完成拖动并恢复拖前值。五处尺寸按版本保存到浏览器本地，切页、刷新或重新打开同一地址后恢复；双击/Enter 只复位并保存该处，其余四处不变。窗口缩小临时限宽不覆盖原值，重新变大恢复原偏好；隐藏查看区保留分栏尺寸。空间不足用资源浮层或横向滚动，不挤破各区下限。实现分别归 T19/T42，验收归 A38/A41，不增加新业务模块。

### 项目内容搜索

搜索由本地服务读取文件，不调用模型、不创建智能体任务。输入后短暂防抖再查询，默认不区分大小写；路径筛选是相对路径包含文字，不是通配符。空关键词不扫描；支持清空、加载中、无文件、无匹配、取消、失败和重试。

范围仅为当前项目的可读取文本，不混其他项目、历史差异、审查快照或 dataRoot。文件树可列出不可搜索文件，但要显示限制；搜索与文件读取共用路径校验、排除目录和大小规则。首版支持 UTF-8（含 BOM）；不支持编码、二进制、超限、不可读文件列明跳过原因。扫描数、结果量、响应大小、时间和并发都有上限；达到上限显示“部分结果”，不把已返回数量写成全项目总数。

结果按文件分组，可折叠；显示命中文件数、匹配处数、行号和高亮片段，同一行两次命中算两处。点击定位文件行；文件已变化或删除则提示重新搜索，不能将旧行号套在新内容上。快速输入、清空、切项目取消旧查询，迟到响应不能覆盖新结果。

页面浏览和搜索允许在编码写入期间读取当前文件，只展示读到的内容与时间，不承诺跨文件一致，也不作为审查证据。它们不申请智能体执行名额、不持有整目录读占用，仍受独立读取限额和路径检查。审查取材与版本核对继续按原规则申请读占用，不能借页面搜索绕过。

### 统一下拉交互

差异范围、新建项目/会话、模型与思考档、认证方式、专用凭据模式、设置及检查配置中的下拉共用一个组件。配色跟随主题：控件约 9px 圆角、菜单约 12px 圆角，柔和阴影、青绿选中项和勾选标记，选项间距充足，长菜单限高并内部滚动。新会话三个选择项使用纯文字触发器，菜单规则不变。

按剩余空间向上或向下展开，弹窗内也不被裁切。方向键、Home/End 移动，Enter 选择，Esc 关闭并回到触发器，Tab 关闭并正常移焦；鼠标点外部关闭，切页不残留浮层。禁用项不可选且说明原因；选择值、验证和认证联动字段保持一致。模型选择使用统一下拉，不为样式改动忙时规则。

### 模型设置页

左侧列出全部接入项，可搜索并筛选“全部、已配置、未配置”；右侧编辑连接和模型。用户只需配置自己用到的，不必填完所有厂商。

- 多家同时保存，不再用一份全局 Key 覆盖其他厂商。首版每个 provider ID 一份生效连接，一份连接可选多个模型；同厂商的地区、产品版本按源码 ID 分开。
- 表单按认证方式显示：API Key、浏览器授权，或厂商专用配置。可替换、清除凭据、重新授权、停用连接；停用后不退回环境凭据继续调用。
- 支持“保存当前”和“保存全部修改”。批量保存逐项返回成功或失败，失败项保留草稿，成功项不回滚；厂商授权仍逐家完成。
- 展示该接入项的模型目录，支持搜索、勾选常用模型、设全局默认。会话从已启用且具备认证条件的模型中选择，模型用 provider ID + model ID 区分；未验证也可选择，但明确标注。
- 两个智能体均选择支持聊天与工具调用的模型，各会话可使用不同厂商；不强制审查与执行使用不同模型。思考档按能力显示，其他模型可查看不可选原因，不增加图片生成等功能。
- 保存只保存配置；目录刷新可能联网，但不发生成请求。“测试所选模型”由用户点击，提示会产生少量调用费用，不自动测试全部模型。
- 分开显示配置状态与测试结果：未配置、已配置、停用；未验证、验证成功、验证失败、需重新授权。配置检查通过不等于真实调用成功。
- 目录刷新失败保留旧目录并标明时间；切换账号或地址后旧动态目录失效。模型下架、连接停用、凭据失效时保留会话原模型引用并提示修复，不偷偷换模型。
- Key、访问令牌和刷新令牌只由服务端保存；浏览器只临时接收用户输入，不写入持久存储、不回显已有密钥。授权链接、设备码和待填写问题可在页面显示。

OAuth 复用厂商现有授权流程，页面承接授权链接、设备码、手动验证码和进度，支持取消、超时及重新授权。AWS/Google 的外部凭据准备按原有机制提示，不承诺页面创建云账号。只有适用的接入项提供自定义地址；授权返回的专用地址不被通用配置覆盖。

### lg-examine 普通审查对话

面向各行业，支持本项目文本、代码、差异及已结束任务记录；不要求先运行编码。用户发送审查要求即进入正常对话，材料用“＋”添加；没有固定五步、准备页和审查轮次。缺要求在对话里询问，模型建议不自动变成用户标准。PDF/Office/图片解析、联网核查与行业系统后续再做。

回复说明范围、材料版本、发现的问题、证据及未验证项。违反明确要求且证据充分才判断不通过；判断通过需要证据覆盖明确要求；缺项就说明无法判定。停止/失败保留已有文字并标未完成，不伪装成功。Markdown 下载绑定指定回复，不另设报告发布流程。

复核直接在原会话继续发送，保留原上下文和记录；新材料重新核对，旧通过结论不复制到新结果。需要另一个独立视角时创建审查分支，分支从用户发送开始，不继承原检查、批准或证据事实。

运行中消息与编码共用默认排队、编辑、撤回、立即插入。新材料先取材再送达；每次请求/工具调用保存所用要求和材料版本，不能通过插入就地修改正在使用的快照。无材料变化可明确沿用已有引用，变化部分重新归档。源目录正在写入时取材受阻，既有快照审查可与编码并发。

审查不装配源项目写工具、任意 Shell 或 Code Mode。指定检查由用户登记命令、参数、材料、预期结果和超时；模型只传 checkId，每个检查意图保存版本与回执。同意图重试不重复运行；明确重跑才新建检查意图。独立副本串行检查，缺环境不自动安装或回源执行，副本不等于系统沙箱。

后台按一次准入执行保存有限政策、已用预算和截止时间，排队/插入及重启不清零；不向用户设置审查轮数。超限停止当前执行，后续由用户明确发送重新准入。等待用户不持续调用模型；未知命令先核对。三种工具审批照常执行，与审查建议和业务结论分开。

一条页面会话绑定一条 Durable 会话；提交、证据、检查和回复按实际 ID 关联，不建 roundId/新轮会话。刷新只恢复位置并查服务端事实，已结束任务不重跑，仍活动的任务按恢复规则处理。

### 模型、侧栏与审查布局补充

- 所有模型入口用当前 pi-ai 目录的 name，缺省完整 model ID，不再用 demo 型号。档位使用 getSupportedThinkingLevels，显示关闭/最低/低/中/高/极高/最高中的实际允许项；切型号用 clampThinkingLevel 归一并说明变化。不支持思考显示禁用，未知模型/能力不可提交，不能固定给两档。
- 已有对话右下配置为纯文字下拉，与新会话一致。无执行、后台收尾、待核对或队列时才可修改原会话模型/思考档。切换智能体走新分支，不修改原会话身份。选择值按草稿/会话保存，默认配置变更不覆盖旧选择。
- 左上图标收起为 60px 窄栏，保留项目简称/状态、新建、智能体、设置、主题。项目悬停显示右侧浮层：顶部完整项目名，第一项新建会话，下面该项目会话；空项目也能新建。浮层限高滚动、不越界；移入不消失，移出延迟关闭；Tab/Enter/方向键/Esc 可用，悬停不切项目。
- 收起状态持久保存；展开还原原宽度和智能体区高度。收起时这两条拖拽线停用，其他三条按可用空间限幅。展开的 220px 下限不作用于 60px 窄栏；刷新、主题切换及设置返回不丢草稿/文件标签。
- 审查消息和输入区共用最大 1100px 的居中容器（含内边距）；窄分栏用可用宽度，不撑出横向页面。智能体、模型和思考档在输入框右下。长代码/表格在自己的区域滚动，项目总览保持现有宽度。

### 新会话分支

入口为会话右键“新会话分支”和对话内切智能体；前者沿用该会话智能体，后者使用所选智能体。都在同项目创建独立会话，复制截至服务端固定位置的用户/助手可见文字背景；未发送文字及材料只从本浏览器对应来源草稿复制。原草稿保留，不自动发送。模型可用则沿用，目标不支持则提示重新选择。

分支显示来源与可折叠背景，保留原作者；历史超限只带最近完整片段并标截断，可查看原记录。服务端保存截止点与背景，原会话后来的消息不进入旧分支。连续分支不重复叠加祖先背景，来源改名/删除不篡改已保存背景。

分支不继承执行、队列、资源占用、工具回执、审批决定或旧审查快照。运行中来源可创建分支；分支启动仍检查资源，不能绕过原任务的写占用。审批模式作为新草稿偏好复制，决定不复制；不能手动改 ID 将来源执行接到分支。

审查分支创建独立 ownerless Durable 会话，进入普通对话；用户自行发送要求，内部执行预算由服务端生成。背景中的“通过”只作参考，不是新结论或证据。同会话继续复核走 U19，不创建分支。

分支创建意图先保存来源 conversationId、末条 entryId、目标和输入指纹，再按固定上界分页取历史；重试不重选来源最新消息。背景不含系统提示、隐藏思考、工具参数/结果原文及凭据配置，也不构造成可执行的历史消息。空历史允许空背景，故障不可伪装成空历史。

右键非当前会话只复制本浏览器可读取到的该会话草稿；没有则为空，不取当前输入框或其他页面未保存文字。草稿版本与创建请求绑定，复制成功不清来源草稿；旧回执不覆盖目标后来编辑的文字。

### 输入材料与标签

“＋”在输入区左下；菜单向上展开，空间不足自动翻转。多选当前项目文件/文件夹，按项目+类型+相对路径去重；父目录与子文件同时选时展开清单去重。Skill 显示“后续支持”且不可提交；不上传任意外部文件。

标签独立放在输入框外上方，左对齐、换行、逐项移除；新会话、编码、审查草稿一致。无材料不留空白区，长路径可查看全名。按草稿保存引用，切会话/刷新/设置返回保留，换项目恢复目标项目自己的草稿及材料，无草稿才为空；原项目草稿保留。只在服务端明确接收后清本次标签；失败或结果未知保留，不因选择材料触发立即插入。

服务端选取时和实际读取前都校验路径、链接、忽略项、缺失与限额，文件夹展开有数量/字节/时间限制，超限明确拒绝并要求缩小范围，不默默漏文件。材料是引用，不承诺锁定选择时的文件内容。编码按实际读取版本处理；审查确认后另行取材冻结。

### 三种真实工具审批

| 模式 | 放行规则 |
| --- | --- |
| 手动审批 | 合规范围内普通只读直接运行；写/编辑/删除、命令及有外部副作用的操作逐项人工确认 |
| 自动审批（默认） | 同样的普通只读直接运行；其余由无工具审批模型判断，明确允许才执行，其余转人工 |
| 完全访问 | 无逐项提示，仍检查身份、范围、模型配置、资源占用和停止/恢复状态；不绕过审查只读规则 |

- 设置指定自动审批模型，默认引用全局默认模型；每次执行冻结完整引用/连接版本，不要求工具调用能力，但须支持所需文本及结构化结果校验。未配置、失败、输出无效或耗尽限额转人工。审批模型不是新内置智能体，也不输出验收报告。
- 审批只针对智能体操作与指定检查；平台保存消息、生成固定归档/报告不重复弹审批，但仍校验写入目标。普通只读由固定工具分类及路径规则判定，不由模型给自己标“只读”。
- 输入区左下显示当前模式；完全访问用醒目文字说明“跳过逐项审批，本机执行”。模式只在空闲且无队列/待核对时改；审查使用同样规则。当前等待不能靠切完全访问解锁。
- 待批卡展示所属会话、工具、目标路径/命令与参数、影响及原因；用户只批准这一项或拒绝。无批量长期授权。参数、目标身份或文件版本前提变化须重新生成请求；模型回复不能当作用户同意。
- 等待期间不执行该动作；模型生成等待工具结果。保留当前资源占用与执行名额，界面说明占用；默认 15 分钟到期拒绝并停止收尾。审查总时限仍继续计时，先到的限制生效。停止会使未决审批失效，释放仍遵守 T13/T14；其他无冲突会话继续。
- 本版初始默认：每执行最多 20 次自动审批请求、单次 30 秒、无自动重试，可在设置调整，新执行才生效；失败转人工，不无限询问模型。审批用量独立记录并计入平台总量，不重复算进业务模型回执。
- 审批记录保存操作摘要/指纹、策略版本、模式、来源、决定、理由与截止时间。刷新/重启恢复待批；已批准但未执行先复查前提，效果未知转待核对，不因已有批准重跑命令。拒绝/失效记录不可被旧页面批准，重复决定幂等，冲突决定拒绝。
- “完全访问”不是新增工具或系统沙箱。lg-examine 即使完全访问也不能写源文件、跑未登记命令；审批不替代要求核对、材料来源校验或资源冲突检查。

### 全局设置结构（U02、U14）

只保留“模型连接、常用与默认模型、基础配置”。三个内容区最大 1040px 居中，目录和表单一起居中；窄窗口收缩且按钮可达。常用与默认模型的目录为“常用与默认、已配置模型”；基础配置按下表分组。点击目录滚动并聚焦标题，当前分组高亮，表单草稿不因定位丢失。

不提供项目选择、项目运行覆盖、单项目并发上限、单独的并发与审查限额页。审查默认限额目录及请求数/检查数/时长表单移除；内部有限预算、指定检查超时、自动审批预算仍保留，用户通过对话开启后续复核轮。

连接表单顶部不展示“被哪些会话占用”的常驻提示。敏感连接修改受阻时，在保存动作旁说明原因；上下文默认值保存不受该锁限制。模型目录下提示“修改上下文仅新建会话生效”；另用状态和测试结果表示是否验证，不以提示代替验证状态。

### 配置什么时候生效

| 配置 | 保存与生效 |
| --- | --- |
| 模型默认、上下文使用上限、输出/思考/压缩覆盖 | 可在执行中保存全局默认。新页面会话/新分支取得新的模型默认版本；既有会话、后续复核轮和重启沿用会话创建时的快照。空闲时显式切模型仍可用，取该会话快照中的目标模型参数；创建时不存在的模型须先显式确认新增该模型快照，不能暗中更新其他模型 |
| 连接请求默认参数 | 保存前要求使用该连接的执行、压缩、队列和待核对全部空闲，发布与准入串行；下一次执行冻结新值。不同连接通过模型请求包装隔离，不把某厂商参数写进所有会话共用的 Harness.stream；审查仍强制 maxRetries=0 |
| Harness 重试、全局压缩、restartLimit、网络代理 | 当前公开设置是全局读取；首版在所有项目执行、队列、后台压缩和待核对全部空闲后才发布，忙时保存明确拒绝并保留表单。不得改完立刻唤醒旧受阻任务。新执行取已发布版本；模型压缩覆盖仍遵守会话快照 |
| 命令、图片、编码工具、自动审批 | 新执行冻结已发布值；不修改正在运行或恢复中的执行。恢复按旧版本装配，版本丢失受阻，不偷用最新默认 |
| 全局并发 | 保存后影响新准入，不取消已有执行；待恢复执行仍计入容量 |
| 凭据、地址、授权、连接启停 | 保留全部使用者空闲检查和串行发布；同一授权的自动刷新照常进行 |

重试名称分清：浏览器重连只恢复消息；模型请求重试只重发失败请求；异常恢复重启运行；命令超时控制子进程。外层重试 3 次、内部 2 次可能最多请求 12 次（不含协议回退），不能再套整任务重试。审查按外层每次实际尝试扣预算；认证失败等不可重试错误直接报错，停止要取消等待且不再发下一次请求。

配置有服务端版本、原子保存和冲突检查。刷新重取已保存值，保留分类、目录锚点、当前厂商与返回位置，不恢复未提交密钥。旧 projects/limits/environment 分类回基础配置，失效锚点回有效分组；旧 results 资源页签回文件。旧审查限额字段从写入契约移除，已有轮预算仍保留。

右栏移除成果页签；审查结论从原消息查看、下载，不删旧报告。文件标签栏隐藏滚动条；仅在标签栏溢出时把鼠标滚轮用于横向滚动，触控板与键盘仍可用；滚动不切文件，选中/恢复的标签自动露出。

## 4 统一行为

### 输入和停止

下列排队行为同时适用于编码和审查。审查新材料准备后再交给模型，未准备好不消费输入，也不替换旧证据。

- 空闲发送开始任务；运行中和收尾中发送默认按顺序排队，没有“补充当前任务 / 完成后执行”下拉。服务端按当前状态准入，不相信页面旧状态；失败保留队列先继续或清空。
- 队列显示在输入框上方，与未发送草稿分开。普通队列每条可编辑、撤回、立即插入；清空只处理点击时服务端捕获的未消费条目，不清后来新增的消息，不停止当前任务。
- 编辑只改该条文字，保存后保持位置、材料和执行配置；编辑窗口不占用输入框草稿，取消不改，纯空白不能保存。版本已变或消息已消费时拒绝覆盖，显示最新状态；未确认编辑不当作已保存。
- 立即插入：仅执行中可选，把原条目改为等待工具轮结束后加入，保留原 ID，不撤回重发、不抢断模型或工具、不停止重开。收尾中禁用并说明原因。等待送达与已加入对话分开显示；等待期间不再提供普通队列编辑入口。
- 插入边界是当前整轮工具结束；多条待插入按原顺序每个边界最多取一条。若直接回答结束，进入下一段 run；最终边界可同时带入第一条普通队列消息，按原队列顺序入对话，不保证插入项独占下一轮。
- 撤回只限仍 queued 的条目；placed 即不能单独撤回，即使尚未收到回复。与边界同时操作时以服务端实际先后为准，不能把已消费显示为撤回成功。重复操作只返回原结果。
- 停止关闭新输入和队列控制，取消本会话执行，清理普通队列及未送达的插入项；保留历史和已改文件，不能只关 SSE。失败取消未送达插入，保留普通队列，明确继续或清空后才接新任务；已消费消息不删。
- 断线、停止中、恢复中、结果待核对时可写草稿，不可发送或改队列。刷新先查原发送/编辑/撤回/插入结果和服务端队列，不自动重发、继续或插入；结果不明保留待确认，旧页面不能覆盖新版。
- 队列按项目+底层会话隔离；分支不复制来源队列。普通排队、待插入都算待处理输入，模型、连接和审批模式不能趁此切换。审查也可排队与插入，实际采用的要求和材料随输入记录。
- 同一轮工具明确串行；read/list/find/search 经确认无副作用后可重跑，write/edit/Shell 保持不可自动重跑。只读工具重跑可能读到更新后的文件。
- 停止和核对解除都是独立请求；重复点击或重启后重试不得停止后来新启动的任务。

### 底栏统计居中

三组统计作为一组，按左项目栏右侧到页面右边的整个底栏居中，包含右资源栏宽度；不按会话区或文件查看区单独居中。执行状态靠右。拖拽、侧栏收起、文件分栏和资源栏显隐后重新计算位置。

宽度不足时统计与状态分两行，统计仍居中；不挤压到重叠，也不盖住输入或停止。两主题、缩放和刷新遵循同一规则。只改位置，数字仍取服务端，未知“—”、部分/估算/未更新标记及非会话页清空规则不变。

### 状态

| 状态 | 用户看到什么 |
| --- | --- |
| 空闲 | 可以提交任务 |
| 执行中 | 工具、回复、检查进度 |
| 正在停止 | 仍在等待命令和任务清理，不能提前显示已停止 |
| 恢复中 | 服务正在检查未完成工作，暂不接收同项目新执行 |
| 待核对 | 某次写入或命令可能已执行，展示对象与已有结果，允许核对后继续 |
| 任务受阻 | 缺少任务定义或版本不兼容；显示原因，不一直假装执行中 |
| 收尾中 | 回复已结束，但 afterRun 任务、后台压缩、进程或归档尚未完成；仍保留相应资源占用 |
| 已结束 | 明确区分正常结束、失败、已停止；restart_limit 按任务类型记录失败或未回答原因，未知副作用仍须核对；检查结果单独展示 |

以上是平台展示状态，不直接改写 Durable 的内部状态枚举。网络断线另显示为连接状态，不能把正在执行的任务改成失败。

### 上游恢复、订阅与配置契约（2026-11-07）

- 连续无进展重启达到 `restartLimit` 后，生成记录 `pi.live.runFailure.reason = restart_limit`，工具记录错误结果，压缩记录 `pi.live.compactionFailure`，其他任务进入 faulted。旧任务不再停放等待重试；不存在本方案可调用的 `retryTask`。核对未知效果并完成旧执行收尾后，用户用新 requestId 明确继续；旧请求只查询旧结果，不重复工具副作用。缺版本/定义的 blocked 与此分开。
- `Submission.wait()` 完成不代表整个会话空闲：输入结算后仍可能运行 `afterRun` 任务。`waitForIdle()` 包含普通所属任务的收尾，但不包含后台压缩；平台另查后台任务、进程、队列和归档，全部满足后才释放名额/写占用，切模型与删除也遵守此边界。只读查看不调用会开启调度的 wait/resume。
- `conversation.watch()` 返回有界历史窗口及内置文档，不是活动模型上下文或全部历史。默认最新 50 条，增长超过 100 条后裁回 50 条；窗口移出的消息不是删除。用稳定 entryId 合并，`before` 标记更早历史；复用 `ConversationTranscript` 的 merge/loadEarlier/fillGap/resume 衔接分页、缺口与重连，不把 SSE 连接序号当永久游标。
- Chord 监听按 `WatchCall.kind` 区分 value/failed；临时 failed 保留最后值且等待恢复，终止按 `WatchEnd.kind` 处理。文档 retired 是独立标记，不等于 null 或整条订阅终止；自有长期文档继续显式订阅。
- 实时 watch 可见未落盘的进度；默认 `progress.persistWithinMs = 1000`，阶段边界也会落盘。断电可能丢最后一段文字/工具进度。累计统计、消息定位及分支截止点以已落盘记录为准；使用 `Session.observeCommits()` 观察持久提交，回调只记录通知，提交外处理读取和网络。重连刷新暂态进度，但不删除已保存历史、不重发输入。
- `ConversationStreamOptions` 已支持 `thinkingBudgets`、`websocketConnectTimeoutMs`；`temperature`、`maxTokens` 仍需公开 Models/Provider 请求包装，逐适配器验证。类型支持不等于每家模型消费；连接/会话参数仍需隔离，不能写成共享 Harness 默认。
- 模型压缩覆盖写入 `AgentChange.compaction.modelOverrides`，按运行时实际 ModelRef（含内部版本映射）匹配，并保留会话快照。优先级为会话模型覆盖 → Harness 模型覆盖 → 会话通用字段 → Harness 通用策略；会话 `enabled: false` 另可压过 Harness 模型覆盖。显式覆盖不随其他会话改变，未覆盖字段仍按现有全局空闲发布规则继承。configure 对 compaction 整体替换，null 清除，undefined 不修改；先校验完整目标，不能把局部字段当深合并。

上述是 T12/T14/T18/T46/T52—T57 的实现约束，对应 A14/A20/A37/A44/A49/A54/A55/A57/A58；不是静态原型已经接入 Durable 的声明。

### 配置和差异

- 会话模型在无活动任务、后台压缩和待处理队列时修改。全部设置为全局默认，不做项目覆盖。上下文等模型默认参数只给新页面会话；已有会话的新复核轮沿用原快照。运行设置的发布边界见下表；并发上限只限制后续准入，降低不取消已有执行，重启保留已准入名额。
- 全局默认值只影响新会话。手动修改连接或授权、停用连接，须等所有使用它的活动任务与后台压缩结束；有保留队列时提示先清空，再修改后重新提交。任务与后台压缩不能半轮切换连接。
- 同一授权的自动令牌刷新由 pi-ai 处理并串行落盘，不受上述手动修改限制。授权失败时保留队列；页面提供“清空队列并去修复连接”，不造成无法重新授权的死循环。
- “本次任务差异”比较任务开始和结束的文件；“工作区差异”保留 Git 当前状态的含义。
- 一次任务按 Durable 的一段 run 记录，可含补充输入；不能把每个模型轮次或每条输入都当成独立任务。
- 用户在任务运行时自行修改文件，标记为可能混有外部改动，不承诺精确归因。
- 命令影响到项目目录之外的文件，不宣称已被项目差异面板完整记录。
- 任务正常结束不等于检查通过；以实际退出码和检查记录展示。
- 完整输出先保存到项目数据目录再提供日志入口；超出保留上限或进程中断时标记不完整，不把系统临时文件当永久记录。
- 业务用量是已保存的模型回执统计，包含压缩；审批调用只记独立审批账再汇总，仍不是供应商账单，崩溃前没有保存的调用可能漏计。

## 5 最少需要保存的数据

| 数据 | 保存位置与用途 |
| --- | --- |
| 全局配置、项目清单、智能体定义目录 | 项目保存 ID、名称、目标和工作目录；智能体定义独立登记，不在项目上存唯一 agentId；同一目录重复关联仍去重 |
| 服务数据实例标识 | 服务端配置中保存的稳定、非敏感标识；浏览器用来区分同地址的不同数据实例，重启不变，不暴露 dataRoot 路径 |
| 模型连接、常用模型、默认模型 | 本地配置目录；按 provider ID 分开，保存地址、专用参数和启停状态 |
| API/OAuth 凭据 | 服务端独立凭据文件或显式环境配置；包含刷新令牌，普通接口仅返回脱敏状态；不与项目代码一起保存 |
| 模型目录缓存、测试记录 | 本地数据目录；记录连接版本和更新时间，配置变化后旧测试结果失效 |
| 会话、输入、消息、工具任务 | 项目的 Durable SQLite，作为执行事实来源；队列和待插入来自 InboxDoc/提交状态，不以浏览器数组为准 |
| 队列条目版本、操作意图和回执 | 同库自有文档，记录原 submissionId、操作 requestId、参数指纹、预期/结果版本；原发送指纹保留；刷新只查结果，不据此重复发送 |
| 项目参与关系与资源占用 | 会话保存 projectId + agentId/版本；参与关系由任务汇总；资源登记保存真实路径、持有会话/执行及读写模式，重启重建，不作为权限数据 |

| 文件基线、差异、完整日志 | 项目 ID 对应的数据目录；数据库保存引用和摘要 |
| 五处布局尺寸 | 浏览器本地独立版本记录；只保存有效数值，按服务数据实例隔离，不属于 Durable 执行数据 |
| 外观主题 | 浏览器同源独立记录，仅 dark/light；与实例、布局及工作位置分开 |
| 新会话草稿、首次发送请求引用 | 按实例+项目保存未发送内容/选择；发送前保存创建 requestId 和指纹，恢复只查询，不自动创建或提交 |
| 名称版本、删除标记、操作回执 | 服务端项目登记及同库自有文档；删除项目先保存意图再补齐子记录，恢复不再调度，历史证据保留 |
| 页面位置、搜索条件、查看标签、显示模式、未发送草稿 | 浏览器本地版本记录，按实例/项目/会话隔离；刷新恢复后向服务端校验引用，不保存文件全文、结果片段或凭据 |
| 发送结果未知的请求引用 | 浏览器保留项目/会话/原 requestId 和输入指纹，用于查询原提交；不是本地执行队列，不据此自动重发 |
| 智能体身份、要求、问题、证据、预算和幂等回执 | 同库项目索引与会话文档保存；workbenchSessionId 绑定唯一 Durable conversationId，消息/执行关联材料与回复。不用随任务退休的任务级文档长期保存 |
| 审查材料快照、检查副本、回复导出 | 项目 dataRoot 下按实际提交/执行归档；文件原子落盘再提交引用。仍被历史回复引用的证据不得清理，副本清理前归档所需日志 |

补充数据：分支的来源/截止点/背景/回执、提交材料清单及审批操作/决定/派发回执保存到服务端自有文档；审批模型配置和限额保存到本地配置。浏览器白名单增加侧栏收起、材料引用和审批模式草稿，不保存审批决定或文件全文。审批与分支采用同项目复合 ID，删除来源保留已被引用的归档。

补充保存：平台会话与 Durable 会话映射、创建请求回执、材料与消息/执行关联；浏览器只保存页面位置及主动定位 entryId。统计从服务端原记录聚合，可保留可重建索引，不另建用量账。推送带范围、版本、完整性和未知原因；workbenchSessionId 不是 ProviderDoc.sessionId。

不额外建设用户表、角色权限表或第二套任务状态数据库。审批使用同库自有文档，独立于 Durable 执行状态。

项目 ID 与 Durable 的数字 ID 必须一起使用：不同项目数据库可能出现相同会话、提交和消息编号。dataRoot 放在项目目录外，避免自身日志和数据库进入代码搜索、差异扫描。

恢复先扫描全部会话与跨项目资源，重建占用和模型归属后开启调度。只读也复查快照哈希；未知命令效果先核对，结束旧执行后用户可在原会话继续发送。等待补充或已结束会话不因刷新、重启自动执行；仍活动的任务按公共恢复规则处理。

已保存的停止先补完，不重新取材或调用模型；核对一项不能意外启动另一项。坏库或占用记录不可读时不能当空闲，保留可能受影响的目录与名额；其他项目仍可查看，已确认无冲突的旧执行可恢复。资源不按超时自动释放，临时文件也须先确认没有未完成取材/发布引用再清理。

## 6 首版暂缓功能

旧会话导入、完整 IDE、独立交互终端、图片与附件上传、文件自动回滚、自动提交推送、通用插件加载、skills/MCP/codemode 全量兼容、专业包市场、通用工作流、自动多智能体协作均不作为 1.0 交付项。两个内置智能体及用户手动审查、整改后复核属于本版；手动会话分支和工具审批纳入本版；自动互审、自动修复及自动批准发布成果后续另拆。


## 7 B 版工作室与 1.0 预留

每个内置、自建及创建助手最终都有独立工作室。选定 B 版，主原型已把左下卡片、方块、收起头像及完整目录改成工作室入口；“开始会话”进入现有页内新会话，首次发送才创建。输入框切换智能体仍是新分支，不打开工作室。

这是 2.0 设计预览，不新增 1.0 在线创建或编辑智能体的交付范围。U20/A38/A43 的直接新建描述用于尚未开放工作室的 1.0 正式页面；预览按本节走查。1.0 必须完成 H32/T60/A61，不能只做静态卡片。

| B 版区域 | 内容与范围 |
| --- | --- |
| 基础信息 | 身份编辑、能力概览、改进提示、最近运行；名称不作为 ID |
| 灵魂 | 智能体个性、语气、判断原则和工作习惯；不改变工具和审批边界 |
| Skills | 分类页签、技能卡片、选择与上传 Skill 包；工具卡明确标注“工具能力” |
| MCP | 单独管理已登记 MCP 能力引用和启用项；连接凭据全局管理 |
| 记忆 | 智能体通用经验，项目专属记忆由项目文件维护 |
| 知识库 | 智能体通用参考资料，保存来源和版本 |
| 自进化 | 发现问题 → 证据 → 通用性判断 → 建议 → 验证 → 用户确认新版本 |
| 运行轨迹 | 时间、项目、任务、状态、打开原会话；缺数据标未知 |

- 布局：保留原侧栏，右侧项目资源暂隐藏。身份卡片 + 八个横向页签，内容最大 1200px 居中；基础页双列，窄处单列。主题、下拉和焦点样式沿用工作台。
- 保存：只有“保存修改”，没有保存草稿或发布按钮；仅新页面会话和显式新分支取得最新配置。旧会话、队列、停后继续、同会话新审查轮和刷新恢复沿用原定义。工作室取消能力只影响新会话；平台实际禁用、凭据失效与停止仍检查后续准入，不撤回已发生的动作。
- 范围：八区均为当前智能体的通用管理，不设项目选择、项目配置或“智能体 + 项目”资料层。项目专属记忆和规则由用户按需在项目根目录维护文件，不在工作室配置或自动汇入智能体通用资料。旧 coding-agent 能加载 AGENTS.md，但还会读取全局目录及项目上级目录；Durable 不会自动接入这套加载器。1.0 由 T08 适配，只自动读取当前项目根目录到目标目录之间的 AGENTS.md；说明和记忆文件须显式列入材料。AGENT.md 不作为自动加载文件名。模型、运行参数和 MCP 凭据全局管理；执行仍按项目隔离。开始会话后在新会话页选项目。轨迹列该智能体各项目记录并标明来源，不能因此向模型开放跨项目材料。
- 创建时点：打开新会话输入页不固定版本，首次发送受理创建意图时才固定；新分支按分支创建意图固定。原请求重试用原版本；同会话复核继续用旧绑定。
- 恢复：产品工作室位置按服务数据实例隔离，已保存定义从服务端读取，浏览器仅存引用；保存结果未知时查原请求回执，不自动重存。已保存定义、工作室智能体和页签可恢复；旧 scope 字段忽略并清除。未保存配置不自动落盘，离开可取消或放弃。返回保留原项目、会话、文件及草稿。失效智能体回目录，删除项目不清空工作室配置；原工作台仍按原失效引用规则回退，断网不当删除。记录跳转核对项目/智能体/会话 ID。缓存损坏、移除或保存冲突不覆盖旧值，输入保留。原型标明尚未接真实会话装配。
- 1.0 预留：定义 ID/来源/版本/内容指纹、能力与实现清单；显式选择版本化扩展，校验工具/提示词段落重名及 wrapper；创建意图和会话绑定；空的长期资料版本引用；统一目录、作用域检查、版本保留和备份恢复。无须在 1.0 实现长期记忆、知识导入、创建助手和自进化任务。

### 灵魂、Skills、MCP 的交互与边界

- “灵魂”突出个性、语气、判断原则和工作习惯，保留原规则内容；改名称不重置已保存定义。项目规则仍由项目文件维护。
- Skills 独立显示“全部、开发、审查、通用、已上传”分类页签和数量；卡片展示名称、简介、类别、来源及选择状态，空分类显示空态。取消顶部技能指引占位行和长条工具列表。现有工具卡标“工具能力”，不把工具开关冒充已安装技能。
- 右上提供“上传 Skill 包”。原型选择 ZIP 后只加入待保存配置，记录文件名、大小和选择状态；可移除，重复文件名提示。它不读取、解压、安装或运行包，保存成功也不代表技能可执行。
- 正式上传是 2.0：服务端校验包、SKILL.md、内容版本和依赖，成功才可保存进定义；原型的文件名检查不能代替内容校验。上传不授予工具、MCP 或项目访问能力，脚本也不自动执行。
- MCP 单独一页，只引用已登记连接及能力；全局管理凭据。工具依赖缺失给出原因，不因勾选就显示已连接。审查仍不能获得源项目写入、任意 Shell 或编码 Code Mode。
- 页签按稳定 ID 保存，不按数组位置恢复；拆分后旧“人设与规则”位置回灵魂，旧能力页回 Skills，记忆/知识库/自进化/轨迹按原含义恢复，失效分类回全部。
- 分类、工作室智能体、页签和返回位置可恢复；已保存技能来自该智能体定义版本。未保存上传不自动落盘，刷新不重新上传、安装、应用或启动任务。定义保存后只影响新会话和显式新分支，旧会话、队列和同会话继续审查沿用原版本。

完整工作室和上传后端仍属 2.0；1.0 的 T60/A61 只预留分别可识别的技能内容版本、MCP 能力引用及工具实现清单，不交付上传安装服务。
