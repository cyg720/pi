# 命令行

在Pi的终端编辑器中输入`/`以搜索当前会话中可用的命令。本页列出了当前Pi版本的内置命令。

扩展、提示模板和技能可以添加命令。因此，Pi中的命令菜单是您会话中加载资源的精确参考。

## 模型和设置

| 命令 | 说明 |
|---|---|
| `/settings` | 打开设置 |
| `/model [provider/model]` | 选择模型 |
| `/thinking [level]` | 设置思考等级 |
| `/scoped-models` | 配置交互式循环使用的模型 |
| `/login [provider]` | 添加提供商认证 |
| `/logout` | 移除提供商认证 |
| `/llama` | 管理配置的llama.cpp路由器上的模型 |

## 会话和上下文

| 命令 | 说明 |
|---|---|
| `/new` | 开始新会话 |
| `/resume` | 切换到另一个已保存的会话 |
| `/name [name]` | 设置会话显示名称，或省略时显示当前名称 |
| `/session` | 显示当前会话信息和统计 |
| `/tree` | 浏览会话树 |
| `/fork` | 从先前的用户消息创建新会话 |
| `/clone` | 在当前位置复制当前会话 |
| `/compact [instructions]` | 压缩当前上下文，可选自定义指令 |
| `/import <path>` | 导入并恢复JSONL会话 |

## 导出和共享

| 命令 | 说明 |
|---|---|
| `/copy` | 复制最后的助手消息 |
| `/export [path]` | 将会话导出为HTML或JSONL |
| `/share` | 上传会话并返回查看链接 |
| `/bug [description]` | 为Pi开发者准备私有故障报告 |

导出或共享会话前请检查会话。会话可能包含提示、工具参数、命令输出、文件内容以及对话过程中暴露的凭证。

## 运行时和项目

| 命令 | 说明 |
|---|---|
| `/trust` | 保存项目信任决策以备未来Pi进程使用 |
| `/reload` | 重新加载快捷键、扩展、技能、模板、主题和上下文文件 |
| `/hotkeys` | 显示活动键盘快捷键 |
| `/changelog` | 显示变更日志条目 |
| `/quit` | 退出Pi |

## 由资源添加的命令

- 扩展可以注册带有自己参数和完成行为的命令。
- 每个提示模板都可用其模板名称访问。
- 技能在启用技能命令时可用为`/skill:name`。

在添加或更改发现的命令资源后使用`/reload`。有关它们的加载和命名规则，请参见[扩展](extensions.md)、[提示模板](prompt-templates.md)和[技能](skills.md)。
