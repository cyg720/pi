# 在终端中使用 Pi

在您希望工作的文件夹中运行 `pi`。Pi 会使用该文件夹来发现文件、指令和配置，并将保存的会话进行分组。如果您尚未安装 Pi 或选择模型，请参见 [快速入门](quickstart.md)。

Pi 加载项目资源时可能会询问您是否信任工作文件夹。有关 [项目信任](security.md#understand-project-trust) 详情，请参见。

转录显示您的提示、Pi 的响应、工具调用、结果和错误。您在编辑器中编写提示和命令。页脚显示当前文件夹、会话、模型、上下文使用情况以及累计使用量和成本。

## 输入提示

输入请求后按 `Enter` 发送。使用 `Shift+Enter` 添加新行，或按 `Ctrl+G` 在您配置的外部编辑器中处理较长的提示。

要包含文件或图片：

- 输入 `@` 搜索文件并将其添加到提示中。
- 按 `Tab` 完成路径。
- 粘贴图片或将图片拖入兼容终端。

## 跟随 Pi 的工作流程

Pi 在工作过程中会显示每个工具调用和结果。按 `Ctrl+O` 展开或折叠工具输出。按 `Ctrl+T` 显示或隐藏思考块。

启动页眉列出 Pi 加载的指令和资源。编辑器边框指示当前思考级别。页脚会随着模型使用上下文而更新，并报告使用情况。

Pi 不会在每次工具调用前询问。请审阅命令和更改的文件，并使用沙箱进行不信任或无人看管的工作。有关 [安全](security.md) 详情，请参见。

## 更改方向

您可以在 Pi 工作时发送更多输入：

| 您想要的操作 | 操作 |
|---|---|
| 调整当前任务 | 输入消息后按 `Enter` |
| 在当前任务后添加工作 | 输入消息后按 `Alt+Enter` |
| 将排队的消息返回编辑器 | 按 `Alt+Up` |
| 停止当前任务 | 按 `Escape` |

使用 `Enter` 发送的消息会在当前响应及其工具调用完成后才处理，然后引导下一个响应。使用 `Alt+Enter` 发送的后续消息会在 Pi 完成当前任务后才处理。中止操作会将排队的消息返回编辑器。

Windows Terminal 保留了一些 Alt 快捷键。有关 Windows 替代方案，请参见 [终端设置](terminal-setup.md)。

## 更改模型或设置

输入 `/` 搜索可用命令。您最常用的命令包括：

- `/model` 选择模型。按 `Ctrl+L` 打开相同的选择器。
- `/thinking` 选择当前模型使用的推理程度。按 `Shift+Tab` 循环切换支持的级别。
- `/login` 和 `/logout` 管理提供商访问权限。
- `/settings` 更改常见偏好设置。

提示模板、技能和扩展可以为同一菜单添加更多命令。有关 [选择模型](models.md)、[配置](configuration.md) 或完整 [斜杠命令参考](slash-commands.md)，请参见。

## 继续或重新开始

Pi 会自动保存会话，除非会话持久性被禁用。

- `/new` 启动新会话。
- `/resume` 打开另一个已保存的会话。
- `/name` 给当前会话起一个可识别的名称。
- `/session` 显示其文件、ID、消息计数、令牌使用情况和成本。

当您想探索另一种方法而不丢失现有工作时，使用 `/tree`、`/fork` 或 `/clone`。使用 `/compact` 减少发送给模型的对话历史记录。有关这些工作流，请参见 [会话和上下文](sessions.md)。

离开 Pi 后，从同一文件夹运行 `pi --continue` 以恢复其最近的会话。

## 运行终端命令

以 `!` 为前缀运行命令，并将输出包含在对话中：

```text
!git status
```

使用 `!!` 运行命令而不将输出发送给模型。

## 复制、导出或分享结果

按 `Ctrl+X` 或运行 `/copy` 复制最后一个助手响应。使用 `/export` 将会话保存为 HTML 或 JSONL。
使用 `/share` 上传会话并获取查看链接。如果使用 Radius 认证，该工件对您的 Radius 组织可见。否则，Pi 会通过 GitHub CLI 创建一个私有的 GitHub gist。请先查看会话，因为它可能包含对话过程中暴露的提示、工具输出、文件内容和凭证。

## 调整终端

全屏模式（默认）会将编辑器和状态区域固定，而会话内容在终端窗口内滚动。普通模式则使用终端的正常滚动缓存。可通过 `/settings` 或 `--tui-mode` 选择模式。

终端对鼠标输入、键盘快捷键和内联图片的支持因平台而异。有关平台特定配置，请参阅 [终端设置](terminal-setup.md)；有关所有可配置快捷键，请参阅 [快捷键](keybindings.md)。运行 `/hotkeys` 可检查当前会话中激活的快捷键。

## 收集诊断信息

在排查终端渲染或会话状态问题时，运行 `/debug`。Pi 会将渲染后的终端行和当前会话消息写入您的 [代理目录](configuration.md#agent-directory) 中的 `pi-debug.log` 文件。

请在分享之前查看该文件。它可能包含提示、模型响应、工具输出、文件内容和终端数据。
