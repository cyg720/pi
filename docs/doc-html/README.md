# Pi 中文离线源码导览

双击 `index.html`，使用现代 Edge、Chrome 或 Firefox 阅读。**不需要网络、不需要启动服务、不需要安装依赖。** 单独复制这个 HTML 到其他目录，也能阅读讲解、源码、Git 历史和架构图。

## 第一版内容

- 八章学习路线：认识项目、包地图、CLI 启动、模型与工具循环、会话与恢复、智能体扩展、服务与持久化、阅读练习。
- 扩展专题包括加载与注册、工具契约、事件边界、状态恢复、并发、取消、UI 模式、重载和 subagent 示例。
- 可点击与自动演示的调用链；源码快照弹窗支持行号、文本定位、继续查找和复制。
- 文档与源码搜索、明暗主题、阅读进度、响应式布局、动画过渡与减少动态效果支持。
- 五类架构图内嵌查看与大图模式，保留图内原有控件。
- 本地 HEAD 可达的全部 Git 历史，支持搜索、包/类型/年份筛选和分页，提供原始说明、父提交、文件列表与增删行数。

## 中文提交解说的范围

当前历史有 6,524 条提交。五条近期提交提供基于提交说明和统计的人工中文解说；其他记录提供**自动元数据中文概述**：变更类型、主题线索、受影响包、文件与增删行数。它们不是逐条补丁审查，也不是所有英文提交说明的完整人工翻译。界面明确区分两者，避免把概述当作源码审查结论。

为任意提交增加更详细中文解说：在 `src/history-notes.json` 中以完整 commit SHA 为键填写说明，再生成。Git 历史只覆盖本地 HEAD 可达提交；不包含其他未合并分支。时间采用作者日期与原始时区，排列采用 Git `--date-order`，合并提交可能没有常规 numstat 文件列表。旧提交中的“当前快照”按钮指向文档生成版本，不代表该旧提交的文件版本。

## 目录结构

```text
doc-html/
  index.html                单文件离线交付物
  build.mjs                 本地生成器，仅使用 Node 内置模块和 Git
  verify.test.mjs           数据、引用、迁移完整性和脚本语法测试
  README.md                 使用与维护说明
  VALIDATION.md             本次验证范围与限制
  src/
    content.mjs             中文章节、调用链、包职责
    history-notes.json      人工中文提交解说
    template.html           页面骨架
    style.css               视觉与动画
    app.js                  交互逻辑
  data/
    history.json            可单独分析的完整提交元数据
    manifest.json           版本、生成时间、源码与图的 SHA-256
  diagrams/
    pi-*.html               移除网络字体后的独立图
    original/               原“图架构”所有文件的原样副本
```

## 更新

在仓库根目录运行：

```powershell
node docs/doc-html/build.mjs
node --test docs/doc-html/verify.test.mjs
```

生成时需要本地仓库、Git 和 Node；阅读时都不需要。生成器不会调用在线翻译、模型 API 或外部 CDN，不修改 package.json 和锁文件。正文是人工维护内容，源码与 Git 元数据自动刷新；接口改变导致定位文本失效时，生成器会报错，要求同步修订正文。

首次生成已把原“图架构”目录全部复制到 `diagrams/original`。后续生成使用这份副本，**不依赖原“图架构”目录**，可以在确认导览后删除原目录。此任务没有删除原目录。

原来的五份 `visual-check.html` 引用了未随原目录提供的 PNG。它们原样保存用于留档，不作为可用图谱页面；阅读器使用五份完整主图。图内原有交互保留，但图内容未逐节点更新审计，应对照当前源码判断。

浏览器可能限制 `file://` 下的剪贴板或持久存储：复制失败时可手动选取源码，进度无法保存时不会阻止阅读。嵌入图使用隔离 iframe，本地生成的分享地址不适合跨机器引用；需要单独打开图时使用 `diagrams/pi-*.html`。外部请求由页面策略禁止。
