# Pi 中文离线源码导览

双击 `index.html`，使用现代 Edge、Chrome 或 Firefox 阅读。**不需要网络、不需要启动服务、不需要安装依赖。** 单独复制这个 HTML 到其他目录，也能阅读讲解、源码、Git 历史和架构图。

## 第一版内容

- 八章学习路线：认识项目、包地图、CLI 启动、模型与工具循环、会话与恢复、智能体扩展、服务与持久化、阅读练习。
- 功能清单详情：16 个大模块、258 项功能与索引条目，覆盖范围内 979 个已跟踪文件、27,144 个代码声明。采用“大模块 > 功能”菜单，支持名称/入口/符号搜索、模块/类别/说明依据筛选。
- 菜单按启动配置、装配、输入执行、工具处理、持久化与展示的业务阅读顺序组织；独立 SDK 与可选分支不表示严格运行时先后顺序。切换功能仅更新详情，保留树的滚动位置和展开状态；离开后返回也会恢复。
- 每个实现文件提供引用关联流程图：引用方/测试 → 当前文件 → 依赖，采用浅色节点、直角连线、箭头和类型引用虚线。可点击节点打开源码；每侧三条关系分页展示，全部关系可翻看。图来自静态引用数据，不声称是运行时调用图。
- 全站右侧正文取消固定宽度上限，自适应占满可用空间；窄屏的图表可在各自区域内滚动。
- 功能详情提供中文用途、触发入口、处理边界、源码版本、资料来源、完整源码、原始注释、声明签名、输入与显式类型、静态双向引用、直接关联测试和 Git 演进。源码可定位到声明行。
- 扩展专题包括加载与注册、工具契约、事件边界、状态恢复、并发、取消、UI 模式、重载和 subagent 示例。
- 可点击与自动演示的调用链；源码快照弹窗支持行号、文本定位、继续查找和复制。
- 文档与源码搜索、明暗主题、阅读进度、响应式布局、动画过渡与减少动态效果支持。
- 五类架构图内嵌查看与大图模式，保留图内原有控件。
- 本地 HEAD 可达的全部 Git 历史，支持搜索、包/类型/年份筛选和分页，提供原始说明、父提交、文件列表与增删行数。

## 中文提交解说的范围

当前历史有 6,565 条提交。五条已有提交提供基于提交说明和统计的人工中文解说；其他记录提供**自动元数据中文概述**：变更类型、主题线索、受影响包、文件与增删行数。它们不是逐条补丁审查，也不是所有英文提交说明的完整人工翻译。界面明确区分两者，避免把概述当作源码审查结论。

为任意提交增加更详细中文解说：在 `src/history-notes.json` 中以完整 commit SHA 为键填写说明，再生成。Git 历史只覆盖本地 HEAD 可达提交；不包含其他未合并分支。时间采用作者日期与原始时区，排列采用 Git `--date-order`，合并提交可能没有常规 numstat 文件列表。旧提交中的“当前快照”按钮指向文档生成版本，不代表该旧提交的文件版本。

    features-app.js          功能菜单、筛选与详情交互

## 更新

在仓库根目录运行：

```powershell
node docs/doc-html/build.mjs
node --test docs/doc-html/catalog.test.mjs docs/doc-html/verify.test.mjs
```

生成时需要本地仓库、Git、Node 和仓库已有的 TypeScript 依赖；阅读时都不需要。生成器不会调用在线翻译、模型 API 或外部 CDN，不修改 package.json 和锁文件。正文是人工维护内容，源码与 Git 元数据自动刷新；接口改变导致定位文本失效时，生成器会报错，要求同步修订正文。

## 功能索引边界

清单覆盖 Git 已跟踪的包 src、coding-agent/examples、tui/native、根/包 scripts 与根 shell 入口。新增文件需纳入 Git 跟踪后才进入下次生成。测试通过直接静态导入关联，文档与二进制不作为独立业务功能。原始注释保留原语言，缺失注释不自动编造。

中文能力说明在 `src/features.mjs` 维护；提供商和示例自动分组，未单独解释的实现进入明确标记的“其余实现、入口与支撑资源”。**全部文件有归属，不表示全部业务语义已经人工逐项讲解。** 静态引用不是精确调用链，文件导出也不等于 npm 公共 API。功能关联提交按当前路径匹配，不追溯重命名。

界面用三种“说明依据”区分中文能力解说、源码规则归类、源码覆盖索引。可以先从中文能力解说建立整体认识，再按文件和符号深入。单文件包含完整快照，当前约 34.7 MiB，首次打开与全文搜索可能比原版稍慢。

首次生成已把原“图架构”目录全部复制到 `diagrams/original`。后续生成使用这份副本，**不依赖原“图架构”目录**，可以在确认导览后删除原目录。此任务没有删除原目录。

原来的五份 `visual-check.html` 引用了未随原目录提供的 PNG。它们原样保存用于留档，不作为可用图谱页面；阅读器使用五份完整主图。图内原有交互保留，但图内容未逐节点更新审计，应对照当前源码判断。

浏览器可能限制 `file://` 下的剪贴板或持久存储：复制失败时可手动选取源码，进度无法保存时不会阻止阅读。嵌入图使用隔离 iframe，本地生成的分享地址不适合跨机器引用；需要单独打开图时使用 `diagrams/pi-*.html`。外部请求由页面策略禁止。
