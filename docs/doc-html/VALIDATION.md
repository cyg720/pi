## 手工验收建议

1. 断网后双击 index.html，切换八个章节与明暗主题。
2. 在“模型与工具循环”点击各步骤，播放/暂停，查看对应源码并搜索下一处。
3. 用全局搜索查找 tool_result，打开讲解与源码；按 Escape 关闭弹窗。
4. 时间线按包、类型、年份和关键词组合筛选；翻页并展开原始说明。
5. 依次打开五幅图和大图，检查缩放与图内主题/导出。
6. 将 index.html 单独复制到其他目录，确认所有内容仍能阅读。
7. 缩窄窗口与放大文字，检查目录菜单、对话框和横向滚动区域。

提交记录的自动中文概述不属于逐条 diff 审计，架构图也保留既有内容；需要进一步深挖的变更应逐条补充人工解说。
