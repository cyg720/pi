# LG Workbench 可点击原型

入口：[index.html](./index.html)。可直接用浏览器打开，无需安装依赖或构建。所有资源在本目录，没有外部字体、图片或模型请求。

也可以从仓库根目录启动静态服务：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

然后打开 http://127.0.0.1:8765 。服务仅供查看静态原型，不是产品后台。

## 页面结构

已合并 B 版智能体工作室：点击左下智能体卡片（列表、方块或收起头像）进入；完整目录同样可进入。保留原侧栏，身份卡片与八个横向页签居中展示，最大 1200px。页签为基础信息、灵魂、Skills、MCP、记忆、知识库、自进化、运行轨迹。灵魂设置个性、表达方式与工作原则，沿用已保存的原人设内容；Skills 用分类卡片展示，MCP 单独选择全局登记的能力。基础页左侧身份、右侧能力和改进、下方最近运行，MCP 概览直接打开 MCP 页。点击“开始会话”进入原有新会话页，返回工作台保留原会话、草稿和文件位置。

Skills 分类为全部、开发、审查、通用、已上传，显示数量；原有工具能力以卡片选用，不冒充已安装技能。右上角“上传 Skill 包”选择 ZIP 后加入待保存配置，可取消选用或移除。仅记录文件名、大小和选用状态，不读取包内容、不安装、不授予工具权限。同名包提示已添加。保存后仅该智能体追加新版本；刷新恢复分类和已保存记录，未保存输入不落盘。旧版本和其他智能体不受影响。

工作室标注“2.0 预览”。八区只管理智能体通用配置，无项目选择或项目资料分层。项目记忆/规则由各项目根目录文件维护。平台拟限定只自动读取项目根到目标目录的 AGENTS.md；旧 coding-agent 还会读全局和上级目录，不能直接当作隔离能力，Durable 也不会自动加载。AGENT.md/自定义记忆文件须显式选入材料；审查使用的项目规则保留来源。模型、运行参数、MCP 凭据全局管理。

保存只追加该智能体的新版本，旧版本保留；新版本不保存旧项目配置或任意额外字段。界面明确：新会话首次发送和显式创建分支时取最新定义；仅打开创建页不绑定。旧会话、队列、停后继续、同会话复核与刷新沿用原绑定。取消能力勾选只影响下一版；平台实际禁用、凭据失效和停止另行检查后续准入，不撤回已发生动作。完整资料清单与索引就绪才切版本是产品要求，原型未实现资料后端。

自进化应用会把演示建议追加到通用规则，不再只改变“已应用”标记；固定样例证据明确标注，不代表真实发现或评测，不复制项目历史。轨迹按固定智能体身份列有效项目的简要记录，跳转前核对归属。“开始会话”进入既有创建页选项目，不立即创建记录。

刷新恢复工作室智能体、页签和已保存定义；位置带固定演示实例标识与最近版本引用，旧 scope 清除。返回保留工作台项目、文件和消息草稿。工作室未保存配置不自动落盘，离开可取消；读失败、坏缓存、已知版本缺失/回退或保存冲突不能用旧值覆盖，当前输入保留。保存前留请求标识和指纹，版本与回执一起写入样例存储；结果未知时提供查询入口，刷新只查原回执，不重存。查无结果仍保持待核对，可主动结束核对后重新编辑。原型待核对引用放在当前标签页 sessionStorage，只覆盖同标签页刷新，不承诺关页后恢复。

页签位置按固定标识保存。旧七区位置恢复到原来的内容，新增 MCP 不会把旧“记忆、自进化、运行轨迹”错位。切页保留当前输入，统一保存为一个新版本。

以上为静态交互，真实会话版本装配、服务实例切换、记忆、知识和 MCP 未接入。验证见 [B 版验证记录](./STUDIO-VALIDATION.md)。

设置的三个页签内容区均在工作区内水平居中，左侧目录和右侧表单整体最大宽度 1040px。模型连接页左侧为厂商列表；常用与默认模型页为“常用与默认模型、已配置模型”；基础配置页为“命令运行、全局执行限额、环境状态、模型请求与重试、上下文自动压缩、网络与代理、图片输入、编码工具高级配置、异常恢复”。点击目录直接定位右侧内容并高亮所选项，不重绘表单、不清除未保存输入；支持键盘 Tab、Enter 和空格。窄处随可用空间收缩，目录与内容各自滚动。

输入框、文本域和有边框下拉聚焦或展开时，只把原有 1px 边框改为淡蓝色，不叠加 outline 或外圈阴影，不改变尺寸。搜索框和任务输入框改容器原边框。发送旁的纯文字下拉继续无背景、无边框，用淡蓝文字/箭头和下划线提示焦点；普通按钮保留键盘焦点。明暗主题都要检查。

审查改为普通对话：用户发送消息直接发起检查，后续要求继续在当前会话中发送。不提供轮次切换、准备表单或固定步骤条。旧请求和结论整理为历史消息，不重复导入；原快照标识和文件标签保留。右栏不提供“成果”，旧缓存恢复为文件页。

已选文件、文件夹标签放在输入框外上方，与输入框左边缘对齐；多项自动换行，无材料时不占空间。新会话和已有对话统一，保留移除操作。

审查消息和输入区与编码会话共用布局，限宽居中；打开文件后随剩余空间收缩。智能体、模型和思考等级靠右横排。

编码与审查空闲时发送消息直接开始；执行中发送默认排队。队列在输入框上方，支持编辑、撤回和立即插入；插入等待当前步骤结束，不中断原任务。队列、待插入消息和草稿刷新保留，停止取消尚未送达的插入。

审查结果作为普通回复追加到消息历史中，继续复查也不创建新会话。只有用户明确创建分支或切换智能体时才建独立分支；旧结论不作为新请求的验收结果。

会话左侧刻度按用户消息定位，编码和审查一致。悬停显示摘要，点击滚动到消息；刷新保留定位，不触发执行。

输入框左下角有“＋”和审批方式。审批菜单向上展开，提供手动审批、自动审批、完全访问；默认自动审批，仅保存演示选择，不接真实权限模块。执行中、有队列或结果待核对时不能修改当前选择。新会话、已有对话、分支和刷新保留各自选择。

“＋”向上展开文件、文件夹和 Skill。文件/文件夹从当前项目样例中多选，显示可移除标签；再次点击取消；切项目恢复目标项目自己的草稿和材料，无草稿才为空，原项目草稿保留。Skill 为禁用占位。发送时把所选样例路径作为参考说明带入消息，发送成功才清除标签；审查与编码一样把路径附在发送消息中。这里只选路径，不上传或读取真实磁盘，也不把选择材料当成授权。

左上角图标可收起/展开左侧栏。收起后为 60px 窄栏，保留新建项目、项目简称及运行提示、智能体头像、设置和主题切换；悬停显示名称。展开恢复原项目栏宽度、项目展开状态和智能体区高度。收起状态刷新保留，切换不重绘会话，不清空输入和文件标签；收起时隐藏左栏宽度与智能体高度拖拽线。

收起时悬停项目简称，右侧显示该项目的会话菜单，第一项为“新建会话”，下面展示会话名称和状态；点击直接进入。空项目保留新建入口，长列表内部滚动。鼠标移入菜单保持展开，移出后稍延迟关闭；支持方向键打开和选项切换、Esc 关闭。悬停本身不切换当前项目。

模型选择项只显示模型名称，不加厂商前缀；内部仍保存完整连接与模型标识，同名模型不合并。右侧资源栏不再显示底部项目名称与样例说明区。

页面底栏按三组展示统计：轮次、步数与生成速度；累计 Token 与缓存命中率；圆环与上下文占用比例。没有回执时显示“—”，不冒充零用量或零费用。场景菜单可切换未知、部分回执、带上下文估算三种样例；缓存全零仍为未知，有值也标“部分”，上下文显示“约”。旧审查统计保留原来源，新请求不借用旧速度或上下文估算；缺回执不凑总数。点击底栏可看口径，切模型后旧速度和窗口估算失效。

已有对话的输入框右下角也提供智能体、模型和思考等级三个文字下拉。切换智能体会立即建立同项目的新会话分支，保留切换时的对话文本和草稿，显示来源并可返回原会话；原执行和队列不转移，新分支不自动执行。审查分支由用户发消息启动，不继承原快照或验收结论；全部对话保留切换入口。

分支背景固定在创建时的消息边界，只保留用户和智能体可见文字、原作者及来源标识，不复制工具结果、内部字段或审批决定。多次分支不重复叠加祖先背景；原会话后续消息不进入旧分支，原草稿保留。背景可折叠查看，但不能作为新审查的证据。

会话右键菜单按“重命名 → 新会话分支 → 删除”排列。新会话分支取自被右键的会话，沿用其智能体、模型与思考等级；无需先打开该会话。项目右键菜单不增加此项。

切换模型和思考等级只影响后续执行，草稿不清空，刷新后保留。执行中、收尾中、有队列或结果待核对时暂不能修改；空闲后可修改后续请求的选择。思考选项跟随所选模型，无思考能力时禁用。分支保存独立的对话背景，原会话删除后仍可查看已保存背景。

模型目录取自当前 `packages/ai` 源码，包含 42 个接入项、1,598 个聊天模型。设置页显示名称、完整模型 ID 和思考档位；长目录单独滚动。新会话、默认模型、会话切换与模拟测试共用此目录。会话选择只列已配置且启用的连接。

每个模型显示源码 `contextWindow`（目录上下文）和 `maxTokens`（最大输出）。在该模型的“配置上下文”中设置使用上限，留空跟随目录，只接受不超过目录窗口的正整数；所有项目共用，按连接与模型分别保存。运行中也可修改上下文默认值；保存后只影响新建会话和新分支。已有会话及其后续复查消息保持创建时的选择，刷新后也保留。这里只演示预算选择，不能扩大厂商容量，不修改历史统计，也未接入实际请求或压缩；全局默认配置仅存内存，刷新恢复目录值；已建会话的选择单独保存。输出预留与压缩阈值是运行层的另一组参数。

思考档按 `getSupportedThinkingLevels()` 的结果展示；切换模型时保留仍受支持的档位，否则按 `clampThinkingLevel()` 调整。只有一个档位时禁用选择；不支持思考时显示“不支持思考”，未知型号不编造能力。刷新保留已选模型和档位。旧演示型号自动换成对应接入项的目录型号，项目、会话和草稿继续保留。

默认暗色，采用深蓝底、蓝灰面板和青绿色强调色。左下角设置旁的太阳/月亮图标切换亮色或暗色；选择单独保存在当前浏览器，刷新和重置演示数据后仍保留。切换不重绘工作区，不清空草稿。下拉、设置、弹窗和文件查看区随主题切换。

新建会话直接进入中间对话区，不弹窗。任务输入框居中；智能体、模型和思考档靠右，位于发送按钮左侧，只显示文字和下拉箭头。首次发送才创建会话，名称默认取首条消息开头 28 个字符，不提供名称填写项。编码和审查发送后输入框都回到底部。无模型时可进入设置，返回继续填写；新会话草稿与页面位置支持刷新恢复。

项目目录路径放在顶部导航下方，长路径省略、悬停显示完整值。左侧项目和会话支持右键或 Shift+F10 打开重命名、删除菜单；重命名刷新保留。删除前确认范围，仅移除原型记录，不删除磁盘文件；项目删除会同时移除其会话。执行中、结果待核对或有队列时暂不能删除。删除当前会话回项目总览，删除当前项目转到其他项目，无项目时显示新建入口，刷新不恢复已删除记录。

五处分界线可拖拽：项目栏右边、会话/文件之间、资源栏左边、顶部栏下边、智能体区上边。悬停显示绿色线，双击恢复该处默认尺寸；方向键微调，Home/End 到边界，Enter 复位，拖拽中 Esc 撤销。

最小尺寸：项目栏 220px、会话区 280px、文件区 320px、资源栏 240px、顶部栏 44px、智能体区 100px。拖到限制就停止，相邻面板也保留最小空间；项目列表至少留 120px 高度。窗口不足时资源栏改浮层；极窄窗口保留 820px 布局并横向滚动。五处尺寸保存在当前浏览器的本地布局偏好中，切页、刷新及重新打开同一地址后恢复；双击只重置对应边界。窗口缩小时临时限制尺寸，不覆盖原偏好。

所有下拉选择统一使用跟随主题的圆角菜单、青绿色选中高亮和勾选标记；长列表内部滚动，底部空间不足时向上展开。支持方向键、Home/End、Enter、Esc 和 Tab，保留原表单值及参数联动。

- 左侧：新建项目、项目与会话列表；智能体固定在底部、设置上方，展示头像、名称与简短描述。默认列表，可切换方块；最多四项，超出独立滚动。当前内置两项。
- 中间：平时显示项目总览或会话；打开文件后左侧保留会话，右侧显示文件查看区，支持多标签切换与关闭。标签栏隐藏滚动条，鼠标滚轮可横向滚动，触控板横向滚动仍可用；滚动不切换选中文件。查看区右上角可整体隐藏，恢复会话全宽；顶部“查看文件”可恢复原标签。
- 页面底栏：三组会话统计在工作台底栏居中，右侧保留执行状态与演示标记；窄窗口优先避免重叠。会话名称只在顶部导航展示，正文无重复标题栏。右侧直接展示文件等标签，无“项目资源”标题栏。
- 右侧：项目文件、搜索、变更；审查会话保留历史材料入口，快照与当前文件明确分开。
- 搜索位于“文件”和“变更”之间：输入关键词搜索当前项目样例内容，支持区分大小写、路径包含筛选、文件分组折叠；点击结果定位行号并高亮，返回保留查询。查询按项目隔离；不提供替换或真实磁盘搜索。
- 设置：完整页面，只保留模型连接、常用与默认模型、基础配置。基础配置合并命令路径、命令超时、全局并发上限、环境状态及模型请求等高级参数；所有项目共用，不提供项目选择或单项目并发上限。运行参数变化在仍有执行、队列或待核对记录时暂不能保存；只改全局并发上限可保存，不取消已有执行；无审查默认限额表单，内部有限预算仍保留。原型配置仍只在内存保存，刷新恢复默认值；旧设置分类恢复到基础配置。没有项目时也能配置。

刷新恢复：当前项目、会话或总览、设置分类及返回位置；每个项目的文件标签顺序、选中标签、查看区显隐；右栏标签、搜索条件、差异筛选、项目展开状态和智能体显示模式。五处分界线尺寸继续保留。新建的演示项目、会话、消息和草稿也保存到当前浏览器，关闭后重新打开同一地址可恢复。

旧审查归档只用于保留历史材料和未收尾状态，不再驱动轮次界面。待核对、审批或收尾记录仍需处理，不能因改成聊天就放开执行。刷新保留消息、草稿、队列和文件来源，不自动重跑。

分支创建前先保存本次请求标识与固定输入。场景菜单可模拟“创建成功但响应丢失”和“请求中断且查无结果”：刷新只查原回执，不重建；查到结果也不跳页或清空新草稿，点击“查看已创建结果”才进入。取材、停止、收尾被刷新中断时显示待核对，不自动重跑。

## 建议演示顺序

1. 默认打开客户服务项目的编码会话。输入草稿，进入左下角设置再返回，草稿保留。
2. 默认已有编码和审查两项执行。停止编码，切到“导出结果 · 独立验收”，审查仍显示运行。
3. 编码运行时直接发送两条消息，默认依次排队。编辑第一条，立即插入第二条；刷新后保留原草稿与待插入标记。用“完成当前执行”场景推进一步，先模拟边界接收插入，原任务继续；再次推进才完成原任务并消费第一条。可单条撤回或清空未消费队列。
4. 连续打开两个文件，在查看区标签间切换；隐藏后会话恢复全宽，再用顶部“查看文件”恢复。当前文件、变更与审查快照分别保留来源标签，最右侧列表仍可操作。
5. 审查直接发送要求，再用右上角演示场景追加审查回复。继续发消息复查，左侧不新增会话；刷新确认消息和草稿还在。
6. 新建项目，选择审查智能体并发送文字要求；不出现标准确认表单。用＋添加材料路径，演示内容不读取磁盘。
7. 设置内搜索厂商。Cloudflare、AWS、Vertex、Azure 显示专用字段；OpenAI Codex 显示模拟 OAuth 流程。填写演示值后保存，验证状态仍与配置状态分开。
8. 使用演示场景切换通过/不通过/暂不能判定、命令结果待核对、失败、断线或暂无模型。暂无模型时新建会话会引导设置，返回后继续创建。
9. 左下智能体区切换列表/方块，点击编码或审查智能体进入 B 版工作室；再点“开始会话”，新会话预选项目和智能体。点击“智能体”标题查看完整目录，目录也可打开工作室。

## 原型边界

- 项目、文件、差异、日志和审查结果为样例；模型名称与档位为本地源码快照。浏览器不读取真实项目文件、不执行命令、不接入 Durable、不调用真实模型或授权服务。
- 目录不代表当前账号有访问权，也不代表联网验证通过。源码更新后，在仓库根运行 `node prototype/generate-model-catalog.mjs` 重新导出；页面“刷新目录”只重新展示已打包的快照，不联网拉取。缺少本地生成数据时先按仓库模型数据流程准备，不能手编目录。
- 工作位置及演示项目、会话记录保存在 localStorage；“重置全部演示数据”才清除这些记录，五处分界线尺寸单独保留。连接配置、授权表单、运行参数仍只在内存中；不持久保存模型密钥。不要填写真实密钥。
- 恢复时校验项目、会话和文件来源，来源失效标签保留错误页，越项目或格式损坏的引用拒绝，失效会话回到所属项目总览。缓存损坏时用初始样例；存储不可用时提示无法保存。保存按浏览器和地址隔离，换端口或清除站点数据后不共享。
- 静态原型没有后台任务：取材、停止、收尾的模拟计时过程被刷新打断后，显示待核对，不伪称操作完成。弹窗、滚动位置和未提交的连接表单不恢复。
- 默认运行中的样例不会自动完成，可在右上角场景菜单推进。切换页面不会暂停样例；停止和收尾有短暂的模拟过程。
- 旧报告转为聊天历史文本；当前通过/不通过回复仅由演示场景产生，不代表真实验收。
- 文件差异仅内置项目的第一段编码执行有样例；其他执行不伪造独立归档。历史、长列表和分页接口未接后端，不能作为持久化验收。
- 并发和冲突是前端状态演示，只检查样例项目与执行名额；真实路径别名、跨项目目录重叠、进程清理、重启恢复与限额执行均待产品开发。
- 请求回执、轮次和统计样例保存在浏览器，演示的是页面行为。正式产品必须从服务端查询回执和统计；多浏览器事务竞争、服务重启、真实分页及审批后台不在此静态原型中实现；页内首次发送目前也未模拟提交回执丢失，不能拿本地样例当后台验收通过。
- 模型表单覆盖常见认证类型与专用字段；OAuth 使用统一演示过程，未逐家重现全部厂商交互。模型连接状态、环境检查也只是模拟。
- 桌面优先；CSS 提供窄窗口折叠规则，本轮未完成跨浏览器、窄窗口和手机兼容验收。
