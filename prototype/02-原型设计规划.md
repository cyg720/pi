# 工作台原型：页面与交互规划

2026-11-07 仅更新模型接入项数量。下文保留早期设计记录；当前普通审查对话、三类全局设置与 2.0 预览规则以 [README](./README.md) 和现行 PRD 为准。

日期：2026-10-28。依据：[需求梳理](./01-需求梳理.md)。用户确认后已制作可点击静态原型，入口为 [index.html](./index.html)，验证记录见 [VALIDATION.md](./VALIDATION.md)。下文保留设计目标，未逐项实测的范围以验证记录为准。

## 1 主布局

```text
┌───────────────────┬─────────────────────────────────┬───────────────────┐
│ 新建项目          │ 项目 / 会话 · 执行状态           │ 文件 搜索 变更 成果    │
│                   ├─────────────────────────────────┤ [审查：本轮材料]  │
│                   │                                 │                   │
│ ▾ 项目 A  2项运行 │ 项目总览 / 编码对话 / 审查流程   │ 项目文件树        │
│   修复问题 [编码] │                                 │ 或变更列表        │
│   验收结果 [审查] │ 工具过程、检查结果、证据与报告   │ 或成果列表        │
│   文档审查 [审查] │                                 │                   │
│ ▸ 项目 B          │                                 │                   │
│                   ├─────────────────────────────────┤                   │
│ 列表独立滚动      │ 当前会话输入 / 标准确认 / 下一步 │                   │
├───────────────────┤                                 │                   │
│ 智能体  列表/方块 │                                 │                   │
│ 头像 名称 简介    │                                 │                   │
│ 最多四个，内滚动  │                                 │                   │
│ 连接状态   设置   │                                 │                   │
└───────────────────┴─────────────────────────────────┴───────────────────┘
```

左侧建议 240—280px，右侧 300—360px，中间自适应；这是初稿尺寸，按实际内容调整。右栏可折叠，窄桌面窗口优先保障中间操作区；不把手机适配加入本轮。

项目名称打开总览，会话名称打开会话。切换会话时中间草稿、右栏执行筛选与材料轮次一起切换；项目文件树仍对应当前项目。智能体放左侧底部、设置上方，默认列表，可切换两列方块；展示头像、名称、简短描述。点击一项打开新建会话并预选当前项目和智能体；点击“智能体”标题进入完整目录。列表四行或方块两行后独立滚动；短窗口缩小区域，不遮挡设置。切换页面和刷新均保留显示模式。

设置采用用户确认的完整页面：保留左侧导航，工作区上方切设置栏目，下方展示厂商列表及表单；退出返回之前的会话。

会话名称只在顶部导航展示，正文取消重复标题栏；配置在输入框右下，底栏只放三组统计与状态；无输入框的审查页配置在正文下方左侧。右侧取消“项目资源”标题栏，直接展示文件等标签，右上角保留面板开关。模型切换保留原有忙时限制；底栏固定，不随正文滚动。总览、目录、设置显示通用状态，不残留会话配置。

## 2 页面清单与 PRD 对照

查看文件时：左侧项目导航 → 中间窄会话区 → 宽文件查看区 → 右侧资源列表。文件查看区顶部横向标签、逐项关闭、右上整体隐藏；标签多时横向滚动。隐藏后会话恢复中间全宽，顶部入口可恢复原标签。没有活动会话时左侧显示项目总览。标签按项目保存，差异执行和快照轮次固定在打开时的来源。

## 3 先打通六条操作路径

| 顺序 | 操作路径 | 原型完成标志 |
| --- | --- | --- |
| 1 | 无项目 → 新建项目 → 选智能体 → 无模型 → 设置连接 → 返回会话 | 不丢新建内容，项目不被绑定到唯一智能体 |
| 2 | 编码输入 → 工具过程 → 排队/撤回 → 结果 → 变更预览 | 输入和结果能对上，差异标明具体执行 |
| 3 | 同项目编码与快照审查并发 → 切换 → 停止其中一个 | 两项状态独立，停止不清空另一项，旧快照标识清楚 |
| 4 | 独立审查 → 缺标准 → 确认 → 取材 → 检查 → 报告 | 无编码历史也可完成；缺证据不能展示通过 |
| 5 | 旧报告 → 新材料 → 新一轮复核 → 比较问题 | 页面会话不变、底层上下文独立；旧报告仍能打开，切智能体才建分支 |
| 6 | 配置部分失败/断线/资源冲突/未知结果 → 对应处理 | 每种异常有原因与下一步，不把所有问题合成重试按钮 |

## 4 制作步骤

1. 需求整理：完成对象、布局、页面、设置范围和状态清单。
2. 布局初稿：先做项目树、编码会话、右栏文件与完整设置页，检查信息密度和操作位置。
3. 交互补齐：接新建、切换、队列、停止、文件预览、差异筛选和返回操作。
4. 审查流程：补标准确认、材料快照、检查、报告和新轮复核。
5. 模型配置：覆盖 43 项列表及各类表单，补授权、批量保存和调用测试的演示状态。
6. 异常与验证：逐条走完六条路径，检查并发状态不串、按钮有效、长列表与窄桌面布局可用。

步骤 2 起才制作界面，不直接在产品 apps 或智能体包中实现后端功能。

## 6 原型验收清单

输入框、文本域和有边框下拉聚焦或展开时，只把原有 1px 边框改为淡蓝色，不叠加 outline 或外圈阴影，不改变尺寸。搜索框和任务输入框改容器原边框。发送旁的纯文字下拉继续无背景、无边框，用淡蓝文字/箭头和下划线提示焦点；普通按钮保留键盘焦点。明暗主题都要检查。

刷新恢复当前项目、会话、总览或设置页；标签顺序、选中项、文件来源和查看区显隐保持。切项目后各自标签、搜索条件不串；新建项目/会话、草稿也能恢复。覆盖缓存损坏、失效引用和重置入口；密钥与授权表单不落浏览器存储。仅验证原型页面保存，不代表 Durable 后台恢复。

新增五处分界线拖拽：项目栏、会话/文件分栏、资源栏、顶部栏和智能体区。范围及最小尺寸以 README 为准；单独的 resizers.js/resizers.css 管理布局，不触发 app.js 会话重建。验收拖过上下限、相邻区最小空间、双击复位、键盘操作、取消拖动、切页/隐藏恢复、窗口缩小及草稿保留；未实测项不得记通过。

下拉框统一规则：9px 控件圆角、12px 菜单圆角、浅绿选中项及勾选标记；选项增大间距，长菜单限高滚动；自动向上/向下展开。覆盖右栏筛选、输入处理方式、新建项目/会话、设置与检查配置。鼠标和键盘选择必须同步原表单值，关闭或切页不能残留浮层。

- 左侧至少包含多个项目，同一项目有编码和多个审查会话；设置不随列表滚走。
- 智能体区位于设置上方，顶部不重复目录入口；默认列表，方块可切换。以超过四项的临时布局样例验证独立滚动，不加入正式内置智能体清单。
- U01—U30 均按下方范围对照；产品待开发能力明确标注，不能把演示按钮算实现。
- 右栏文件、变更、成果与材料快照标明来源；切项目不会残留上个项目的数据。
- 编码与审查采用不同输入操作；审查运行中不出现发送补充到当前轮的按钮。
- 所有 43 项模型接入项可找到；普通 Key、OAuth、五类专用连接均能查看对应字段。
- 保存、验证、授权状态分开；设置页面退出保留会话，敏感字段不写入本地持久存储。
- 展示并发、目录冲突、正在停止、待核对、无模型、空项目、三类报告和草稿状态。
- 文件多标签与会话并排；隐藏/恢复/关闭末项不丢草稿，重复文件不增重复标签，切项目不串文件，快照和执行来源不随会话变化。长日志关闭后回到工作区。
- 在常用桌面宽度检查无关键按钮遮挡；演示数据始终与产品真实执行能力区分。

原型验收只证明布局和交互；产品持久化、真实工具隔离与故障恢复仍按 PRD 的 A01—A56 实施验证。
