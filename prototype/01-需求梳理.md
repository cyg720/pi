# 工作台原型：需求梳理

日期：2026-10-28。需求已梳理，可点击静态原型已制作；未接入真实产品功能。入口：[index.html](./index.html)。

依据：[1.0 功能清单](../PRD/1.0/01-功能清单.md)、[验收用例](../PRD/1.0/03-验收用例.md)。原型规划见 [02-原型设计规划](./02-原型设计规划.md)。

## 1 已确定与暂定内容

用户已确定：左侧项目列表，每个项目下列多个会话；右侧项目文件、变更等；设置固定在左下角，集中配置连接和运行参数。

沿用 1.0：单用户、本地部署、Web 优先；基于 pi-durable；内置 lg-codeing-agent、lg-examine；项目和智能体独立，同项目可并发多个会话；覆盖全部 42 个模型接入项。

用户已确认可点击静态原型、完整设置页，退出设置保留原会话。中间作为主要工作区；智能体目录保留独立入口；右栏可折叠。默认深蓝暗色，左下单图标切换亮色；五处分界线与工作位置刷新保留。

## 2 四种对象，不能混用

| 对象 | 表示什么 | 界面位置 |
| --- | --- | --- |
| 项目 | 一组目标、目录、资料和成果，不绑定唯一智能体 | 左侧一级列表；点击打开总览 |
| 智能体 | 平台提供的专业能力，可用于多个项目 | 独立目录；新建会话时选择 |
| 会话 | 某项目内使用一个固定智能体的独立对话 | 项目下面的列表；点击打开工作区 |
| 执行/审查轮次 | 会话内的一次工作；审查每轮使用独立运行上下文，页面会话不变 | 对话执行记录；审查进度与轮次入口 |

例：同一项目下有“修复导出问题（编码）”“验收导出结果（审查）”“检查需求文档（审查）”三个会话。后两项可读各自快照，与编码同时进行；它们不是项目的三个成员或三个专属智能体。

项目下展开会话只是导航分组，不是会话 fork 树。审查复核保留当前页面会话，页内切换旧轮。切换智能体或右键“新会话分支”才新建独立会话，固定复制可见背景和草稿，不接管执行、队列或审批决定。

## 3 左侧：项目与会话导航

从上到下：产品名称、新建项目、项目/会话列表、底部智能体区、连接状态与设置。

- 智能体区固定在设置上方，展示头像、名称、简短描述；默认列表，可切换为两列方块。列表最多四行，方块最多两行四个，超出在区域内滚动；短窗口允许减少可见项，保证设置可用。
- 点击智能体打开新建会话，预选当前项目和该智能体，仍可换项目；点击区域标题打开完整目录。当前仅展示两个内置智能体，不为凑满四个新增能力。

- 项目行：名称、展开按钮、运行中会话数、创建会话入口。点名称进入项目总览，点展开按钮只展开列表。
- 会话行：标题、智能体短标签、执行状态；选中项清楚高亮。长标题截断，可查看完整标题。
- 列表单独滚动，设置始终留在左下角；会话较多时提供加载更多，保留历史访问能力。
- 创建项目：名称、目标、关联已有目录或创建空目录；首版输入服务端本机路径，不要求选择智能体。
- 创建会话：当前项目、智能体、模型、支持的思考档；无可用模型时提供“去配置模型”，返回后保留已填内容。
- 切项目、切会话、打开设置不会停止执行。会话草稿分别保留，不能把上一会话内容带到下一会话。
- 项目和会话支持右键重命名、删除；会话另有新会话分支。产品删除为持久标记，保留磁盘文件和证据；原型仅移除样例记录。不做分支树、团队成员或自动派单。

## 4 中间：项目总览与会话工作区

新建会话直接进入居中输入页，不弹窗、不填名称；首次发送才创建，标题取开头 28 个 Unicode 字符。任务、配置、材料按项目保存，来回切换和刷新不串。输入区左下材料/审批，右下智能体/模型/动态思考档，材料标签在框外上方。

审查准备、执行、报告最大宽度 1100px，居中并随分栏收缩；无输入框页配置在正文下方左侧。旧报告、标准、材料与配置按轮保存；旧轮缺失明确提示，不借当前轮。

### 项目总览

展示名称、目标、目录、参与过的智能体、正在执行的会话、近期成果。提供“新建会话”，允许打开某项进度或结果。

没有会话时显示“选择智能体开始工作”。一项完成不代表整个项目完成；多项并发分别展示状态，不能只有一个当前任务。

### 编码会话

- 顶部导航：项目/会话名称、右栏开关；正文不重复设置会话标题栏。
- 页面底栏：轮次/步数/速度、累计 Token/缓存命中、上下文占用三组统计和状态；缺回执显示未知，部分与估算注明。配置选择放输入框右下。
- 正文：用户消息、模型回复、可展开的工具调用、命令输出、检查结果；历史可向前加载。
- 底部输入：空闲时发送；执行中选择“补充当前任务”或“完成后执行”；队列可查看、撤回未消费输入，失败后继续或清空。
- 停止只针对选中的执行，明确包含该会话的待执行输入；先显示正在停止，清理结束才显示已停止。
- 结果：改动说明、实际检查、未完成事项、用量；未运行检查就写未运行，未知费用不写成零。
- 智能体身份固定。会话模型仅在没有活动任务、后台压缩和待处理队列时可改。

### 审查会话

共用外层布局，中间换成审查流程：输入要求和材料 → 确认标准 → 取材 → 逐项检查 → 报告 → 手动复核。

- 输入：原要求、标准、文本材料或项目文件范围，可选择本项目已结束任务。
- 检查配置：命令、参数、预期结果、所需文件和依赖、超时；可不配置，此时只做静态审查。
- 缺标准：展示模型建议，编辑确认后再正式取材。等待时不显示模型持续运行。
- 进度：验收项、取证、反例、疑点核实、已用预算、实际检查回执。
- 报告：通过、不通过、暂不能判定；逐项证据、问题、未验证项；支持下载 Markdown。
- 运行中补充只留草稿；停止后才能带入新轮。不提供编码式“完成后执行”。
- 复核：选择旧报告与新材料，建新轮；没有正式报告的停止/失败草稿也可另开一轮。
- 停止、失败或超限保留草稿，不显示正式通过；不自动交给编码智能体修复。

## 5 右侧：文件、变更与成果

右侧直接从标签开始，不设置“项目资源”标题栏；收起和展开统一使用页面右上角开关。

| 标签 | 内容 | 必须说明的范围 |
| --- | --- | --- |
| 文件 | 项目目录树、文本预览入口、缺失或不支持类型提示 | 当前项目的实时文件，与选中智能体无关 |
| 搜索 | 内容关键词、区分大小写、路径包含筛选；按文件分组、匹配计数、行号与高亮，点击定位只读预览 | 当前项目文件；不混入其他项目、历史差异或审查快照 |
| 变更 | 文件列表、新增/修改/删除、本次执行差异与工作区差异切换 | 本次执行差异要选择具体执行；工作区可能包含用户和其他会话改动 |
| 成果 | 检查记录、编码结果、审查报告 | 标明来源会话、执行或轮次，点开进入对应详情 |

选择审查会话后增加“本轮材料”标签：只展示本轮快照、证据、缺失项和版本。文件预览顶部明确写“项目当前文件”或“审查快照 · 第 N 轮”，不能默默切换来源。

搜索位于“文件”和“变更”之间，输入即更新结果。查询条件按项目分别保留；切回标签或刷新后恢复条件。支持清空、文件分组展开/折叠、空关键词/无匹配/无文件提示。当前仅做原型样例的字面内容搜索，不提供替换、正则或真实磁盘检索。

打开文件后，中间分成左侧会话、右侧文件查看区，最右侧文件列表保留。文件支持多标签切换、逐个关闭；同一来源的同一文件重复打开只激活已有标签。查看区右上角可整体隐藏，隐藏后会话恢复中间全宽；顶部“查看文件”可恢复已打开标签。关闭最后一个标签同样恢复全宽。打开文件不丢草稿，也不停止任务。

标签按项目隔离，切回项目恢复其标签；切换同项目会话不改变已打开快照的来源。当前文件、指定执行差异、工作区差异、各审查快照分别识别，不能只按文件名覆盖标签。查询命中继续定位查看区中的行号。刷新保留标签顺序、选中项及查看区显隐；首版只读，不增加代码编辑器、终端、Git 提交或回滚按钮。

刷新回到原项目和会话，原来是总览或设置则恢复该页。新建的演示项目、会话和草稿也保存，避免只有页面引用却找不到记录。模型配置和授权表单不在此保存；记录失效时回退有效项目，文件来源失效则保留错误标签，不替换成当前文件。

审查报告只针对快照。当前源目录正在被编码占用时显示“当前版本未核对”，不能因此阻止旧快照报告展示，也不能显示当前版本已通过。

## 6 左下角设置：集中入口，分清作用范围

打开完整设置页，替换中间和右栏；左侧导航保留。关闭设置返回原项目、会话和草稿。设置分以下栏目，不把全部参数堆在一张长表单里。

| 栏目 | 具体内容 | 生效范围 |
| --- | --- | --- |
| 模型连接 | 42 个接入项、认证、地址及专用字段、启停、刷新目录、测试、批量保存 | 全局，每个 provider ID 一份连接 |
| 常用与默认模型 | 按厂商选常用模型、全局默认模型、能力说明 | 默认用于新会话；不替换旧会话模型 |
| 项目运行 | 先选项目，再设命令环境、路径、超时和已有运行参数 | 指定项目；忙时不可改的字段说明原因 |
| 并发与审查限额 | 全局/项目并发上限、审查请求数/检查数/执行时长默认值 | 降并发不杀现有执行；新审查限额只影响新轮 |
| 本地环境 | PowerShell、Bash、Git、rg 状态与缺失说明；维护说明入口 | 服务端本机；不增加浏览器远程终端或一键安装 |

模型连接页内部为“接入项列表 + 当前连接表单 + 模型目录”：

- 列表包含全部 42 项，支持搜索和按配置状态筛选，未配置也可见。
- 普通 Key、OAuth、AWS、Vertex、Azure、Cloudflare 按真实能力显示字段，不统一做成 Key + URL。
- OAuth 展示链接、设备码、输入/选择问题、进度及取消，不增加平台账号登录。
- 保存当前、保存全部修改；批量部分失败逐项显示，保留失败草稿。
- 已保存凭据不回显；空 Key 表示保留，清除单独操作。密钥不写浏览器持久存储。
- 配置状态与调用测试结果分开；保存不自动测试，测试前说明会产生模型调用费用。
- 连接占用时显示哪些会话正在使用，包含取材、后台压缩和收尾；保留队列可清空后修复连接。
- 账号/地址变化后旧目录及测试结果失效；缺凭据、模型下架不自动换模型。

完整接入项名称和专用字段沿用 PRD，不在本文件维护另一份清单。

## 7 需要画出来的状态

| 类别 | 状态与用户下一步 |
| --- | --- |
| 初次使用 | 无项目 → 新建项目；无模型 → 配置模型；空会话 → 输入任务 |
| 执行 | 运行中、取材中、收尾中、正在停止、正常结束、失败、已停止 |
| 审查 | 待确认标准、检查中、报告草稿、已发布、需新轮复核 |
| 冲突 | 名额已满或目录占用；显示持有项目/会话，允许查看和手动重试，不显示自动排队承诺 |
| 连接 | 浏览器断线、重连；任务状态保留最后已知值，不误标失败 |
| 恢复 | 恢复中、待核对、版本/定义缺失受阻；核对旧操作后结束旧执行，再继续或另开轮 |
| 材料 | 当前版本一致/已变化/未核对、缺文件、快照损坏、文件过大或不支持 |
| 配置 | 已配置但未验证、验证失败、授权取消/过期、保存部分失败、忙时禁止修改 |

状态不能只靠颜色区分，必须有文字；操作不可用时说明原因和下一步。普通页面不展示 admissionId、数据库表或 Harness 等实现术语。

## 8 分界线拖拽

输入框、文本域和有边框下拉聚焦或展开时，只把原有 1px 边框改为淡蓝色，不叠加 outline 或外圈阴影，不改变尺寸。搜索框和任务输入框改容器原边框。发送旁的纯文字下拉继续无背景、无边框，用淡蓝文字/箭头和下划线提示焦点；普通按钮保留键盘焦点。明暗主题都要检查。

项目栏右边、会话与文件之间、资源栏左边可调宽度；顶部栏下边、智能体区上边可调高度。最小值为项目栏 220px、会话 280px、文件 320px、资源栏 240px、顶部栏 44px、智能体区 100px；同时保留项目列表至少 120px 高度。到边界停止，不挤没相邻区。窗口不足时资源栏浮层显示，极窄窗口横向滚动。

悬停高亮和调整光标；拖动不重建会话、不丢草稿或停止任务。双击恢复该处默认，键盘方向键微调、Home/End 到上下限、Enter 复位，Esc 撤销当前拖动。尺寸作为浏览器本地偏好共用，切项目/设置及刷新后保留；隐藏文件区不清其宽度。原型验证见 VALIDATION.md，产品开发仍按 PRD 实施。

## 9 首版原型不扩大范围

1.0 实现手动审批、自动审批、完全访问三种工具审批；原型只演示模式选择。审批不是多用户权限。不增加账号权限、插件市场、自定义智能体编辑器、MCP/codemode 设置、自动互审、自动修复、附件上传、移动端专版或完整 IDE。设置集中化不等于把未纳入 1.0 的功能做成空入口。

当前静态原型的模型调用、授权、文件读取、命令、恢复和并发全部使用明确标注的演示数据。原型验证页面和操作关系，不证明 Durable 或资源隔离已经实现。已实现范围与限制见 [使用说明](./README.md)。
