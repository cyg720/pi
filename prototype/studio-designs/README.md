# 智能体工作室三版设计

入口：http://127.0.0.1:8765/studio-designs/

这是独立的 2.0 设计稿，不替换工作台首页，不调用模型或访问项目文件。

| 版本 | 内容组织 | 适合情况 |
| --- | --- | --- |
| A 目录式 | 左侧七区目录，右侧配置；沿用现有设置页思路 | 日常配置，优先落地 |
| B 总览式 | 身份、能力、改进卡片；横向七区标签 | 先看整体情况，再进入配置 |
| C 分栏式 | 左侧目录、中间编辑、右侧范围说明 | 经常区分通用配置和项目资料 |

用户已选 B 版，并合并到主原型左下智能体入口。此目录保留三版比较稿；后续以主原型为准。

## 共同规则

- 七区：基础信息、人设与规则、Skills 与能力、记忆、知识库、自进化、运行轨迹。
- 内置和自建智能体都有工作室。当前提供两个内置智能体和一个自建示例。
- 模型与运行参数使用全局设置，不在工作室重复配置。
- 项目规则、记忆、知识库标明范围；切换项目不会创建另一个智能体。
- 保存修改生成新的演示版本，只供新会话使用；不提供“保存草稿”。
- 自进化展示证据、建议和验证结果，确认后应用到新版本。
- 运行轨迹只显示时间、项目、任务、状态和详情入口。
- 使用现有原型的配色、自定义下拉和焦点边框。支持明暗切换、左侧收起、窄窗口布局。

## 演示边界

- 配置保存在独立浏览器键 `lg-studio-designs-v1`，不写原型的工作台状态。
- 三版共用保存的演示配置，方便在相同内容下比较布局。
- 页面内切换区域保留未保存输入；未保存内容刷新后不保留。
- 来源、知识资料、运行记录、改进验证是示例，不代表真实执行。
- 新会话仅展示绑定版本，不启动真实任务。全局设置和项目入口返回原型首页。
- 当前未接入真实配置注册、项目资料读取、版本冻结和 durable 执行服务。
